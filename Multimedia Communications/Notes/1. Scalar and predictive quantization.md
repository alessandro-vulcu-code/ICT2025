# Scalar and Predictive Quantization

> [!abstract] Overview
> This lecture covers scalar quantization (SQ) — definitions, optimal design, and predictive coding — through the lens of the rate-distortion trade-off: how much quality you lose for a given compression ratio, and how to keep that loss small.

---

## Definitions

### Scalar quantizer
Almost always, it is just a staircase function:
![[Pasted image 20260311110223.png|500]]

A **scalar quantizer (SQ)** maps a real-valued input to a finite discrete set:

$$Q : x \in \mathbb{R} \;\to\; y \in \mathcal{C} = \{\hat{x}^1, \hat{x}^2, \dots, \hat{x}^L\} \subset \mathbb{R}$$

Three things fully specify it:
- Thresholds $t^1 < t^2 < \cdots < t^{L+1}$: partition $\mathbb{R}$ into $L$ decision regions (cells) $\Theta^i = (t^i, t^{i+1})$
- Levels $\hat{x}^i \in \Theta^i$: the representative value (codeword) assigned to each cell. The graph below also represent the quantizer: the thresholds and the levels completely determine the quantizer.
	![[Pasted image 20260311110319.png|500]]
- Dictionary $\mathcal{C} = \{\hat{x}^1, \dots, \hat{x}^L\}$: the finite output alphabet

The quantization noise (error) for a single sample is:

$$e(n) = x(n) - Q[x(n)]$$
[[L02_scalar_predictive_quantization.pdf#page=11|Example: on SQ at page 11 of this document]]

### Rate

The rate $R$ (bits per sample) and number of levels $L$ are related by:

$$R = \log_2 L \quad \Longleftrightarrow \quad L = 2^R$$

In practice $R$ must be an integer, so $L$ is a power of 2 (e.g., $L = 256 \Rightarrow R = 8$ bpp).

### Distortion

For a deterministic signal of length $N$, distortion is the MSE:

$$D = \frac{1}{N}\sum_{n=0}^{N-1} d[x(n),\, Q[x(n)]] = \frac{1}{N}\sum_{n=0}^{N-1}|e(n)|^2$$

For a random signal $X(n)$, it is the variance of the error process:

$$D = \sigma_Q^2 = \mathrm{E}\!\left[|X(n) - Q(X(n))|^2\right]$$

SNR and PSNR in dB:

$$\mathrm{SNR} = 10\log_{10}\frac{\mathrm{E}\{X^2\}}{D} \qquad \mathrm{PSNR} = 10\log_{10}\frac{A^2}{D}$$

where $A$ is peak amplitude. PSNR uses peak power as reference and is the standard metric for images and audio.

### Mathematical reminders: integer mapping functions

| Function | Operator | Definition | Rounding direction | Example |
|---|---|---|---|---|
| Floor | $\lfloor x \rfloor$ | Greatest integer $\leq x$ | Towards $-\infty$ | $\lfloor -2.7 \rfloor = -3$ |
| Ceil | $\lceil x \rceil$ | Smallest integer $\geq x$ | Towards $+\infty$ | $\lceil -2.1 \rceil = -2$ |
| Fix | $\mathrm{fix}(x)$ | Drops the fractional part | Towards zero | $\mathrm{fix}(-2.7) = -2$ |
| Round | $\mathrm{round}(x)$ | Nearest integer $= \lfloor x + 0.5 \rfloor$ | To nearest | $\mathrm{round}(2.5) = 3$ |

## Uniform quantization

**Uniform quantization (UQ)** uses equal-size cells. For input range $A$ and $L$ levels, the step size is:

$$\Delta = \frac{A}{L}$$

Each cell has size $\Delta$ and is represented by its midpoint.

### Unsigned data (range $(0, A)$)

Thresholds at $t^i = (i-1)\Delta$. Encoder/decoder:

$$i = \left\lceil \frac{x}{\Delta} \right\rceil \quad \text{(encoder)} \qquad \hat{x}^i = i \cdot \Delta - \frac{\Delta}{2} \quad \text{(decoder)}$$

$$Q(x) = \Delta \cdot \left\lceil \frac{x}{\Delta} \right\rceil - \frac{\Delta}{2}$$
![[Pasted image 20260311111125.png]]
### Signed data — mid-tread quantizer

For signed data (range $(-A/2,\, A/2)$), zero must be a quantization level. This is the **mid-tread** quantizer, which requires an odd number of levels $L$. Small fluctuations near zero get mapped to zero, suppressing noise:

$$i = \mathrm{round}\!\left(\frac{x}{\Delta}\right) \quad \text{(encoder)} \qquad \hat{x}^i = \Delta \cdot i \quad \text{(decoder)}$$

$$Q(x) = \Delta \cdot \mathrm{round}\!\left(\frac{x}{\Delta}\right)$$

The output is the closest multiple of $\Delta$.
![[Pasted image 20260311111209.png]]
### Signed data — mid-rise quantizer

With an even number of levels, zero falls on a threshold $t^{L/2+1} = 0$. Any small value near zero gets quantized to $\pm\Delta/2$ depending on its sign — this is the **mid-rise** quantizer. When a noisy signal oscillates around zero, the quantizer amplifies rather than suppresses the noise, causing **granular noise enhancement**.

### Deadzone quantization (DZQ)

A practical extension of mid-tread: the central cell (around zero) is wider than $\Delta$, controlled by threshold $\tau$:

$$i = \begin{cases} \mathrm{sign}(x) \cdot \left\lfloor \frac{|x| + \tau\Delta}{\Delta} \right\rfloor & \text{if } |x| \geq \tau \\ 0 & \text{if } |x| < \tau \end{cases}$$

$$\hat{x} = \begin{cases} \mathrm{sign}(i) \cdot \Delta\!\left(|i| + \frac{1-\tau}{2}\right) & \text{if } i \neq 0 \\ 0 & \text{if } i = 0 \end{cases}$$

![[Pasted image 20260311111303.png|600]]

Widely used in video codecs because it zeroes out small-valued coefficients efficiently — essentially sparsification.

### UQ wrap-up

> [!info] Minimax optimality of UQ
> For fixed range $A$ and fixed levels $L$, UQ achieves the smallest possible maximum error (minimax criterion). The maximum error is $\Delta/2$; any non-uniform modification can only increase it. UQ is optimal when only the worst case matters, not the statistical distribution.

## Rate-distortion theory

### Probability theory refreshers

Two results used in the derivation:

1. **Uniform RV** $X \sim \mathcal{U}(a,b)$: $f_X(x) = \frac{1}{b-a}$, variance $\mathrm{Var}(X) = \frac{(b-a)^2}{12}$

2. **LOTUS**: For a continuous RV $X$ with PDF $f_X(x)$:
$$\mathrm{E}[g(X)] = \int_{-\infty}^{+\infty} g(x)\, f_X(x)\, dx$$

### RD curve for uniform quantization (exact, uniform input)

**Setup**: $X \sim \mathcal{U}(-A/2, A/2)$, UQ with $L$ levels. Goal: find $\sigma_Q^2 = \mathrm{E}[(X - \hat{X})^2]$.

Within each cell $\Theta^i$, the input is locally uniform over width $\Delta$, so the error $E = X - \hat{x}^i \sim \mathcal{U}(-\Delta/2, \Delta/2)$. Applying LOTUS and summing over all $L$ cells:

$$\sigma_Q^2 = \frac{1}{A}\sum_{i=1}^{L}\int_{-\Delta/2}^{\Delta/2} t^2\, dt = \frac{1}{A}\cdot L \cdot \frac{\Delta^3}{12} = \frac{\Delta^2}{12}$$

Substituting $\Delta = A/L = A \cdot 2^{-R}$:

$$\boxed{D = \frac{\Delta^2}{12} = \frac{A^2}{12 L^2} = \frac{A^2}{12} \cdot 2^{-2R} = \sigma_X^2 \cdot 2^{-2R}}$$

The last equality holds because $\sigma_X^2 = A^2/12$ for $X \sim \mathcal{U}(-A/2, A/2)$. SNR:

$$\mathrm{SNR} = 10\log_{10}\frac{\sigma_X^2}{D} = 10\log_{10} 2^{2R} \approx 6R \;\mathrm{dB}$$

This is the "6 dB per bit" rule: each additional bit gives roughly 6 dB of SNR.

### High resolution (HR) approximation for arbitrary PDFs

**Hypothesis**: $L \to \infty$ (equivalently $\Delta \to 0$). Under this assumption, $p_X$ is approximately constant within each cell, so the error is still $\mathcal{U}(-\Delta/2, \Delta/2)$ regardless of the input PDF:

$$D = \frac{\Delta^2}{12} = \frac{A^2}{12} \cdot 2^{-2R}$$

For an arbitrary non-uniform PDF, UQ is no longer matched to the input. Introducing the **load factor**:

$$\gamma^2 = \frac{X_{\max}^2}{\sigma_X^2} = \frac{A^2/4}{\sigma_X^2}$$

the distortion and SNR become:

$$D = \frac{A^2}{3} \cdot 2^{-2R} = \frac{\gamma^2}{3}\,\sigma_X^2 \cdot 2^{-2R} = K_X\,\sigma_X^2 \cdot 2^{-2R}$$

$$\mathrm{SNR} \approx 6R - 10\log_{10}\frac{\gamma^2}{3}$$

The load factor $\gamma^2$ penalizes SNR when the signal's peak is much larger than its RMS value — a real problem for Gaussian signals, where $\gamma^2 \gg 1$.

## Optimal scalar quantization

### Problem formulation

Given a PDF $p_X(x)$, find thresholds $\{t^i\}$ and levels $\{\hat{x}^i\}$ that minimize distortion for fixed rate $R$. Two regimes:

- **High resolution**: analytical solution available
- **Low/arbitrary resolution**: use the Lloyd-Max algorithm

### Optimal RD curve in high resolution

Under the HR hypothesis, the optimal (non-uniform) quantizer achieves:

$$\sigma_Q^2 = c_X\,\sigma_X^2\, 2^{-2R}$$

where $c_X$ is the **shape factor**, determined solely by the shape of the PDF:

$$c_X = \frac{1}{12}\left[\int_{\mathbb{R}} p_U^{1/3}(t)\, dt\right]^3, \quad U = \frac{X}{\sigma_X}$$

| PDF | Shape factor $c_X$ |
|---|---|
| Uniform | $1$ |
| Gaussian | $\frac{\sqrt{3}}{2}\pi \approx 2.72$ |

A Gaussian signal requires 2.72× more distortion at the same rate, because probability mass concentrates near zero while the tails still need coverage. Equivalently, the optimal quantizer for Gaussian inputs gains about $\frac{1}{2}\log_2(2.72) \approx 0.72$ bits over UQ at equal distortion.

### Lloyd-Max algorithm (non-HR optimal quantization)

At low rates with few levels, there is no closed-form solution. The **Lloyd-Max algorithm (LMA)** finds a locally optimal quantizer by alternating two conditions:

1. **Initialize** dictionary $\mathcal{C}^{(0)} = \{\hat{x}_0^i\}_{i=1,\ldots,L}$ (uniform or random)
2. **Nearest neighbor rule** — optimal thresholds for a fixed dictionary: midpoints between adjacent levels

$$t^i = \frac{\hat{x}^i + \hat{x}^{i+1}}{2}, \quad i \in \{1,\ldots,L-1\}$$

3. **Centroid condition** — optimal levels for fixed thresholds: conditional mean of $X$ within each cell

$$\hat{x}^i = \mathrm{E}[X \mid X \in \Theta^i] = \frac{\int_{\Theta^i} u\, p_X(u)\,du}{\int_{\Theta^i} p_X(u)\,du}$$

4. **Stop** when relative distortion reduction falls below $\varepsilon$:

$$\frac{\sigma_{Q,(k-1)}^2 - \sigma_{Q,(k)}^2}{\sigma_{Q,(k-1)}^2} < \varepsilon$$

> [!info] Convergence of Lloyd-Max
> LMA does not guarantee global optimality — the result depends on initialization. But distortion is non-increasing at every step, so the algorithm always converges to a local minimum.

When the PDF is unknown, replace the theoretical centroid with sample means over training data assigned to each cell. This is k-means clustering.

### Summary: RD curves for scalar quantization

| Scenario | Distortion $D(R)$ |
|---|---|
| UQ, uniform input | $D = \sigma_X^2 \cdot 2^{-2R}$ |
| UQ, arbitrary input (HR) | $D = K_X\,\sigma_X^2 \cdot 2^{-2R}$, $K_X = \gamma^2/3$ |
| Optimal SQ (HR) | $D = c_X\,\sigma_X^2 \cdot 2^{-2R}$ |
| Optimal SQ (any $R$) | Lloyd-Max (local optimum) |

In all HR cases: $D \propto 2^{-2R}$, i.e., SNR grows at ~6 dB/bit.

## Predictive scalar quantization

### Motivation: the limits of plain scalar quantization

Plain SQ treats each sample independently, ignoring statistical dependencies between neighbors. For correlated signals (natural images, speech), this is inefficient:
- High variance $\sigma_X^2$ means high distortion at a given rate
- The codebook ignores redundancy in the signal

If a signal is predictable from its past, the prediction error has much smaller variance than the original. Quantizing the error instead of the signal gives lower distortion at the same rate.

### Sparse signals

> [!info] Definition
> A signal is **sparse** if most samples are zero or near zero. Sparse signals have low variance and can be quantized with low distortion at low rates, because most samples just map to zero.

Natural signals are not sparse in their original form, but become sparse after prediction or linear transforms — the topic of the next lecture.

### Predictive quantization scheme (open loop)

1. **Encoder**: predict $x(n)$ from past samples as $v(n)$; compute prediction error $y(n) = x(n) - v(n)$; quantize to get $\hat{y}(n) = Q[y(n)]$
2. **Decoder**: receive $\hat{y}(n)$; reconstruct $\hat{x}(n) = \hat{y}(n) + v(n)$

The quantization error is preserved:

$$q(n) = y(n) - \hat{y}(n) = x(n) - v(n) - \hat{x}(n) + v(n) = \bar{q}(n)$$

Distortion on $y$ equals distortion on $x$ — prediction does not add noise, it just reduces the variance of what gets quantized.

### Prediction gain

Total SNR decomposes as:

$$\mathrm{SNR}_P = 10\log_{10}\frac{\sigma_X^2}{D} = \underbrace{10\log_{10}\frac{\sigma_X^2}{\sigma_Y^2}}_{G_P} + \underbrace{10\log_{10}\frac{\sigma_Y^2}{D}}_{G_Q}$$

- $G_P$ = **prediction gain**: SNR improvement from variance reduction via prediction
- $G_Q$ = quantizer gain on the error signal

Prediction helps only if $\sigma_Y^2 < \sigma_X^2$.

**Example**: For $X(n) \sim \mathcal{N}(0, \sigma^2)$ with autocorrelation $\mathrm{E}[X(n)X(m)] = \sigma^2\rho^{|n-m|}$ and predictor $V(n) = X(n-1)$:

$$\sigma_Y^2 = 2\sigma^2(1 - \rho), \qquad G_P = 10\log_{10}\frac{1}{2(1-\rho)}$$

Prediction gain $G_P > 0 \Leftrightarrow \rho > 1/2$.

### Linear predictors

Linear predictors are optimal for Gaussian processes. The order-$P$ predictor:

$$v(n) = -\sum_{i=1}^{P} a_i\, x_{n-i} \qquad \Rightarrow \qquad y(n) = x(n) - v(n) = \sum_{i=0}^{P} a_i\, x_{n-i}, \quad a_0 = 1$$

The prediction error $y(n)$ is the output of an FIR analysis filter $A(z) = 1 + a_1 z^{-1} + \cdots + a_P z^{-P}$ applied to $x(n)$.

**Optimal coefficients** (Yule-Walker equations) — minimize $\sigma_Y^2 = \mathrm{E}[Y^2(n)]$:

$$\sigma_Y^2 = \sigma_X^2 + 2\,\underline{r}^t\,\underline{a} + \underline{a}^t\,R_X\,\underline{a}$$

Setting $\partial\sigma_Y^2/\partial\underline{a} = 0$:

$$\underline{a}^{\mathrm{opt}} = -R_X^{-1}\,\underline{r}, \qquad \sigma_Y^2 = \sigma_X^2 + \underline{r}^t\,\underline{a}^{\mathrm{opt}}$$

where:
- $\underline{r} = [r_X(1), \ldots, r_X(P)]^t$ is the autocorrelation vector
- $R_X$ is the $P \times P$ Toeplitz autocorrelation matrix with $[R_X]_{ij} = r_X(|i-j|)$
- Autocorrelation estimated from data: $\hat{r}_X(k) = \frac{1}{N}\sum_{n=0}^{N-1-k} X(n)\,X(n+k)$

### Impact of predictor order

Increasing order from 2 to 4 typically improves $G_P = \sigma_X^2/\sigma_Y^2$. But there is a **screening effect**: immediate neighbors already capture most mutual information, so distant past samples add little once nearby ones are included. Higher orders cost more computation for diminishing PSNR returns.

### The drift problem

> [!question] Why does the naive open-loop scheme fail?
> The encoder uses original (non-quantized) past samples to compute $v(n)$, but the decoder only has *reconstructed* (quantized) past samples. The two predictors diverge over time — **drift** — causing unbounded reconstruction error.

**Solution — correct DPCM scheme**: Both encoder and decoder must use the same data — the reconstructed past samples $\hat{x}(n-i)$. The encoder maintains an internal copy of the decoder's state:

$$v(n) = \mathcal{P}[\hat{x}(n-1), \hat{x}(n-2), \ldots, \hat{x}(n-P)]$$

This architecture is **Differential Pulse Code Modulation (DPCM)**.

### Local adaptation: block-wise approach

Real images are non-stationary — textures vary spatially, so a single global predictor is suboptimal. Dividing the image into $M \times M$ blocks and fitting a local predictor for each helps, at the cost of side information.

**Overhead**: total rate increases by $\frac{N \cdot B}{M^2}$ bits/sample, where $N$ is filter order and $B$ is bits per coefficient.

| Block size | Advantage | Disadvantage |
|---|---|---|
| Small | Adapts to local statistics | High overhead from filter coefficients |
| Large | Minimal overhead | Predictor misses local features |

### Practical performance: the role of entropy coding

Comparing PQ vs. UQ using $R = \log_2 L$ as the rate is misleading because:

1. $\log_2 L$ vastly overestimates the actual entropy of the prediction error — most quantization indices are zero
2. At low rates, the predictor receives heavily quantized data, degrading prediction quality
3. The correct comparison uses actual coding rate via entropy coding

When entropy coding is applied to the quantization indices (whose histogram peaks sharply around zero), the numbers get interesting: on the "lena" image, PQ + entropy coding achieves $\Delta\mathrm{PSNR} \approx 20\;\mathrm{dB}$ at 1 bpp compared to UQ + entropy coding, or an 86% rate reduction at 30 dB.

## Wrap-up

- **UQ**: $D = K_X\,\sigma_X^2\, 2^{-2R}$ — simple, minimax-optimal, SNR ≈ 6 dB/bit
- **Optimal SQ**: same exponential behavior $c_X\,\sigma_X^2\,2^{-2R}$; at low rates, use Lloyd-Max
- **Both UQ and optimal SQ applied directly to images/audio compress poorly** — neither exploits signal structure
- **DPCM** is effective only when combined with entropy coding

For DPCM to actually work, three things matter:
1. The predictor must run on **quantized** (reconstructed) past samples — not originals — to avoid drift
2. The signal must be **sufficiently correlated** ($\rho > 1/2$ for first-order prediction)
3. **Entropy coding** of the quantization indices is what makes the rate savings real

> [!abstract] Next lecture
> Entropy coding: short codewords for frequent (near-zero) indices, longer ones for rare large errors. This is where the gap between theory and codec performance closes.
