## What is scalar quantization?
![[Pasted image 20260227115353.png]]
Any number between $t_4$ and $t_5$ in input is quantized as zero in output. We have intervals and one signal is projected as one number.
We have $L=7$ levels
The $t$ are **thresholds** and they determine a *partition* of the input interval. 
* Each $\Theta^i = (t^i, t^{i+1})$ is a quantization region or cell
* Any number in $\Theta^i = (t^i, t^{i+1})$ is quantized as $\hat{x}^i$
We assume we have real numbers. We need infinite bytes to rappresent them.
With 3 bits we can represent 8 levels
So quantization is used to manage the number of bits to represent the levels.

Scalar quantization (SQ) is a function $Q$ from $R$ to a discrete set called *Dictionary:*
$$Q : x \in \mathbb{R} \to y \in \mathcal{C} = \{\hat{x}^1, \hat{x}^2, \dots, \hat{x}^L\} \subset \mathbb{R}$$
where:
- **C**: is dictionary, it is a discrete subset of $\mathbb{R}$;
- $\hat{x}^1$: quantization level, code-word;
- $e = x - Q(x)$ is **quantization noise**;
- $\Theta^i$ is decision regions or cells

Regions and levels completely define the SQ;
Regions are typically defined as intervals;
Therefore, thresholds and levels also completely define a SQ;

### Parameters
- **Input Interval**: $(-A, A) = (-1.25, 1.25)$
- **Step Size ($\Delta$)**: 
  $$\Delta = \frac{2A}{L} = \frac{2.5}{5} = 0.5$$

### Quantization Table
| Cell $\Theta^i$ | Thresholds ($t^i, t^{i+1}$) | Level ($\hat{x}^i$) |
| :-------------- | :-------------------------- | :------------------ |
| $\Theta^1$      | $(-1.25, -0.75)$            | $-1$                |
| $\Theta^2$      | $(-0.75, -0.25)$            | $-0.5$              |
| $\Theta^3$      | $(-0.25, 0.25)$             | $0$                 |
| $\Theta^4$      | $(0.25, 0.75)$              | $0.5$               |
| $\Theta^5$      | $(0.75, 1.25)$              | $1$                 |

> [!NOTE]
> All cells have the same size ($\Delta = 0.5$) and each level is the center of the corresponding cell.
