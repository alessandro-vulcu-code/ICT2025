JPEG Standard

▶ Image compression standard based on DCT
▶ Specified in 1991, adopted in 1992
▶ It describes only the decoder: this insures interoperability and implementation competition
▶ It can work on multi-component (color) images, but we will describe its operation on one component, the other being identical
  ▶ One-component images are assumed to be gray-scale
  ▶ Three-component images are assumed to be YCbCr, unless specified otherwise in a marker
