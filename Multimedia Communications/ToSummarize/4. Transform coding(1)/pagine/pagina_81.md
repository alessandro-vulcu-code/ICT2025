Dealing with the frequency leakage

If we first create a symmetric mirror $x_{\text{SYM}}$ of the signal $x$, when we periodize it, there will be no jump, removing the frequency leakage.

With symmetrical periodization, we double the signal period, i.e., we double the number of coefficients.

However, using some mathematical property of the DFT, we can arrange thing is such a way that the coefficients are symmetrical too, thus only half of them is needed.

This process produces the Discrete Cosine Transform of the input signal.
