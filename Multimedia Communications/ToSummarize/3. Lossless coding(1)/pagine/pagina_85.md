Arithmetic coding

Problem: estimation of $P(X^K)$, where $K$ can be as large as the size of the message

In the previous example, symbols were supposed independent, $P(X^K) = \prod_{i=1}^{K} p(x_i)$

Symbols statistics can be learned during the encoding process (adaptivity): we store an occurrence count vector, and we update (at the encoder and the decoder) according to some agreed rule
