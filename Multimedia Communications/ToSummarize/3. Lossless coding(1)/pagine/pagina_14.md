McMillan’s theorem and Kraft’s inequality

▶ McMillan’s theorem: Decodable codes do not improve performance with respect to instantaneous codes
We can focus only on instantaneous codes

▶ Kraft’s inequality: there exists an instantaneous code with lengths $\{\ell_1, \ldots, \ell_M\}$ if and only if:

$$\sum_i 2^{-\ell_i} \leq 1$$

We have a mathematical characterization of instantaneous codes

▶ It is a necessary and sufficient condition for the existence of a prefix code.
▶ If the sum equals 1, the code is said to be complete (or maximal).
▶ It sets the stage for Shannon’s Source Coding Theorem.
