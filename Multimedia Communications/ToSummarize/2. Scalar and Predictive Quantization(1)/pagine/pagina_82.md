Optimal quantization

For a given probability density function $p_X(x)$, we want to find the quantizer minimizing distortion for a given rate. Problem equivalent to determine thresholds $t^i$ and levels $\hat{x}^i$.

Solutions:

- Analytic Solution in high resolution: $D = c_X \sigma_x^2 2^{-2R}$
- If the high resolution hypothesis is not met, we can find a local optimum with the Lloyd-Max algorithm
