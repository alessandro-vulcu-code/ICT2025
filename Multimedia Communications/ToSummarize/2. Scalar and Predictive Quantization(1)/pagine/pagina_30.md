# Mathematical Reminders: Round Function

**Operator:** round(x)

- **Definition:** Maps $x$ to the nearest integer
- **Behavior:** Usually implemented as $\lfloor x + 0.5 \rfloor$
- **Examples:**
  - round(2.51) = 3
  - round(2.49) = 2
  - round(-2.3) = -2
- **Usage:** allow a straightforward implementation of uniform quantization
