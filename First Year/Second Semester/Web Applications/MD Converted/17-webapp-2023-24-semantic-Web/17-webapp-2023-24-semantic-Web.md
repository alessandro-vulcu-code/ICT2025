## Slide 9 - Resource Description Framework (RDF)

Resource Description Framework (RDF)

RDF is a framework for representing information in the Web

The core structure of the data model is a set of RDF triples, each consisting of
a subject (URI), a predicate (URI) and an object (URI or literal)

Asserting an RDF triple says that some relationship, indicated by the predicate, holds between
the resources denoted by the subject and object. This statement corresponding to an RDF triple is
known as an RDF statement

A set of such triples is called an RDF graph. An RDF graph can be visualized as a node
and directed-arc diagram, in which each triple is represented as a node-arc-node link

An RDF document is a document that encodes an RDF graph in a concrete RDF
syntax, such as RDF/XML, N-Triples, Turtle, JSON-LD, RDFa, or TriG

## Slide 18 - Linked (Open) Data

Linked (Open) Data

Linked Data is about using the Web to connect related data that
wasn’t previously linked, or using the Web to lower the barriers to
linking data currently linked using other methods

the basic idea is to apply the general architecture of the World Wide Web to
the task of sharing structured data on global scale

The term Linked Data refers to a set of best practices for
publishing and interlinking structured data on the Web

Linked Open Data is Linked Data that is explicitly published under
an open license

Heath, T. and Bizer, C. (2011). Linked Data: Evolving the Web into a Global Data Space. Morgan & Claypool Publishers, USA.
http://linkeddatabook.com/editions/1.0/

## Slide 19 - Linked Data Principles

Linked Data Principles

Use URIs as names for things

it advocates using URI references to identify, not just Web documents and digital
content, but also real world objects and abstract concepts.

Use HTTP URIs, so that people can look up those names

it advocates the use of HTTP URIs to identify objects and abstract concepts, enabling
these URIs to be dereferenced (i.e., looked up) over the HTTP protocol into a
description of the identified object or concept

When someone looks up a URI, provide useful information, using the
standards (RDF, SPARQL)

it advocates use of a single data model for publishing structured data on the Web – the
Resource Description Framework (RDF)

Include links to other URIs, so that they can discover more things

it advocates the use of typed hyperlinks to connect not only Web documents, but any
type of thing. Hyperlinks in the Linked Data context are called RDF links in order to
distinguish them from hyperlinks between classic Web documents

## Slide 22 - FAIR Principles

FAIR Principles

Findable

Interoperable

(Meta)data are assigned a globally unique and
persistent identifier

(Meta)data use a formal, accessible, shared, and
broadly applicable language for knowledge
representation.

Data are described with rich metadata

(Meta)data use vocabularies that follow FAIR
principles

Metadata clearly and explicitly include the
identifier of the data they describe

(Meta)data include qualified references to other
(meta)data

(Meta)data are registered or indexed in a
searchable resource

Reusable

Accessible

(Meta)data are richly described with a plurality of
accurate and relevant attributes

(Meta)data are retrievable by their identifier using
a standardised communications protocol

(Meta)data are released with a clear and
accessible data usage license

The protocol is open, free, and universally
implementable

(Meta)data are associated with detailed
provenance

The protocol allows for an authentication and
authorisation procedure, where necessary

(Meta)data meet domain-relevant community
standards

Metadata are accessible, even when the data
are no longer available
