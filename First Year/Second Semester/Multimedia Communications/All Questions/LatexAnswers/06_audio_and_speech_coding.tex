\begin{questionbox}{Domanda 39}
Explain masking in the auditory system: define frequency masking and \textbf{temporal masking} (pre/post-masking) with their time-scale orders of magnitude.
\end{questionbox}


\begin{itemize}
  \item \textbf{Auditory masking} → strong sound makes weaker sound inaudible.
  \item Codec use → hide \textbf{quantization} noise below \textbf{masking threshold}.
  \item \textbf{Frequency masking} → \textbf{simultaneous masking}; strong component at $f_0$ raises threshold around nearby frequencies, mostly same critical band.
  \item \textbf{\textbf{temporal masking}}:
  \item pre-masking → few ms before masker;
  \item post-masking → up to about $100$-$200$ ms after masker, depending on level/content.
\end{itemize}



\begin{questionbox}{Domanda 40}
What is the critical band and how does it relate to the audibility condition of a set of sinusoids close in frequency?
\end{questionbox}


\begin{itemize}
  \item \textbf{Critical band} → frequency interval processed roughly by same cochlear auditory filter.
  \item Bandwidth increases with center frequency.
  \item Close sinusoids interact inside same band.
  \item Audibility condition:
\end{itemize}


$$
\sum_i g_i^2 > S_0(f_n)
$$


\begin{itemize}
  \item $g_i^2$ → sinusoid powers.
  \item $S_0(f_n)$ → absolute hearing threshold near frequency $f_n$.
\end{itemize}



\begin{questionbox}{Domanda 41}
(A\&S Comp.) Explain the difference between Source-Based (Parametric) coding and Sink-Based (Perceptual) coding.
\end{questionbox}


\begin{itemize}
  \item \textbf{Source-based / parametric coding} → models signal production.
  \item Speech → source-filter model of vocal folds + vocal tract.
  \item Goal → intelligibility and low latency at very low bitrate.
  \item \textbf{Sink-based / perceptual coding} → models listener perception.
  \item Audio codecs → auditory masking + critical bands.
  \item Goal → transparent quality by removing inaudible information.
\end{itemize}

\begin{questionbox}{Domanda 46}
(A\&S Comp.) Why are Line Spectrum Frequencies (LSF) preferred over direct \textbf{quantization} of \textbf{LPC} coefficients ($a_i$)?
\end{questionbox}


\begin{itemize}
  \item Direct \textbf{LPC} coefficient \textbf{quantization} → can create unstable synthesis filters.
  \item \textbf{LSF} → represent \textbf{LPC} filter through roots on unit circle.
  \item Stability condition easier to enforce by preserving interlacing/order:
\end{itemize}


$$
0<\omega_1^{(P)}<\omega_1^{(Q)}<\omega_2^{(P)}<\cdots<\pi
$$


\begin{itemize}
  \item If \textbf{quantization} disturbs order → decoder can restore valid ordering.
\end{itemize}



\begin{questionbox}{Domanda 47}
(A\&S Comp.) Regarding the Opus audio codec, what is the primary technical advantage of its hybrid design?
\end{questionbox}


\begin{itemize}
  \item \textbf{Opus} combines:
  \item \textbf{SILK} → \textbf{LPC}-based, efficient for speech and low bitrates;
  \item \textbf{CELT} → \textbf{MDCT}-based, efficient for music/general audio and low delay.
  \item Advantage → seamless adaptation across speech/music, bitrate, latency; useful for WebRTC.
\end{itemize}
