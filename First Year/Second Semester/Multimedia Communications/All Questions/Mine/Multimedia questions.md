1. [+] Describe the three types of redundancy exploited by compression (statistical, psychovisual, semantic) and give a concrete example of each.

• Statistical redundancy: when samples complete or repeats ex. video codec predicts current frame from previous frame, then encodes small residual.

• Psychological redundancy: Human Visual system cannot perceive some detail/eners ex. JPEG heavily quantizes h-F DCT coefficients.

• Semantic redundancy: exact examples not necessary when meaning/text matters.

$$\text{sensitivity} = \frac{\lambda}{\text{minimum detectable contrast}} \left[ \frac{\text{cycles}}{\text{degree}} \right]$$

High-frequency errors are often less visible so high-frequency transform coefficients can be quantized more easily.

3. [+] Explain masking in the auditory system: define frequency masking and temporal masking (pre/post-masking) with their time-scale orders of magnitude.

Masking: $S(f_0, \theta^2, f)$ functions. The idea is that we do not encode information that could not be heard

• Frequency masking: simultaneous masker at $f_0$ hides freq. mainly within same cultural band. (shring sound hides weak sound)

• Temporal masking:

- Pre-masking: hides sound occurring shortly before marker onset (2-5 ns)
- Post-masking: hides sound after masking ends (100-200 s)

4. [+] What is the critical band and how does it relate to the audibility condition of a set of sinusoids close in frequency?

Critical band = frequency interval processed by roughly same auditory filter in cochlea. Width increases with center freq.

For N sinusoids close to frequency $f_n$, the audibility condition is

$$\sum_{i=1}^{n} g_i^2 > S_0(f_n)$$

Power of sinusoids

Absolute hearing threshold near $f_n$

=0 several individually inaudible sinusoids can become audible when combined power exceeds threshold.

2. [PDF] Define the concept of a deadzone in a quantizer and explain why it is frequently used in lossy compression systems.

In a quantizer, a Deadzone is an enlarged internal around zero. All input values inside it map to record value 0.

In lossy compression, Deadzone is used because many transforms or prediction residual coefficients are small and pacephilly unimportant. Mapping them to zero:

• Increases sparsity
• Improves entropy coding efficiency
• Lowers bitrate
• Often causes little visible/ audible distortion

More zeros means more compression, but too wide deadzone removes useful details and creates artifacts.

- Prediction residual

5. [PDF] Draw the scheme of a linear predictive quantization system and motivate the structure, with particular attention to the decoding loop on the encoder side (the predictor must be fed the same data at encoder and decoder to avoid drift).

$$\sum x(n) \quad y(n) \quad Q \quad \tilde{y}(n) \quad \sum x(n) \quad \tilde{y}(n)$$

Linear predictor $P$

Encoder

Decoder

Linear predictor: $v(n) = -\sum_{i=1}^{p} a_i \tilde{x}(n-i)$

Residual: $y(n) = x(n) - v(n)$

Reconstruction: $\tilde{x}(n) = \hat{y}(n) + v(n)$

Encoder does not quantize $x(n)$ directly. It predicts $x(n)$ from past samples, quantizes only residual $y(n)$.

If prediction is good, residual has low variance and many near-zero values, so quantization + entropy become efficient.

Key point: encoder must use reconstructed past samples $\tilde{x}$ instead of original past samples $x$.

Initial interval [0, 1]

7. [+] State Shannon's Source Coding Theorem (bounds on average length $L$ vs entropy $H$) and what it guarantees.

Shannon Source coding = entropy is the lower bound for longer coding average length:

$$I > H(x)$$

For a practical prefix code, one can choose lengths close to ideal:

$$l_i = \Gamma - \log_2 p_i$$

Which guarantees:

$$H(x) \leq I \leq H(x) + 1$$

No longer uniquely decodable code can have average length below entropy, but there exists a code whose average length is less than one bit/symbol above entropy.

8. [+] Explain Exp-Golomb coding: for which source statistics it is suited and why it is used in video standards for syntax elements.

Exp-Golomb coding is a universal variable length code for non-negative integers. Small values get short codewords while large values get progressively longer codewords.

It is suited for sources where small integers are much more probable than large ones.

Video synthesis uses Exp-Golomb for syntax because it is:

• Simple to encode/decode
• Prefixed free→ instant decoding
• Good for space near-zero data

... 

It is not optimal like authored coding when accurate probabilities are known, but is excellent for symble robust syntax coding

Question: Explain the GOP structure and I/P/B frame types: role, dependencies, and impact on compression, random access and latency.

GOP = Group of Pictures, a coded sequence organized around independently coded and predictively coded frames

• "I" frames: Intra frames, access points of our video, decoding starts here. Used for random access and error reset but cost many bits.

• "P" frames, predict from previous reference frames and improve compression with manageable delay.

• "B" frames: Between frames, predicts from past and future reference improving efficiency but requiring reordering and adding latency.

Question: What are the roles of VCL and NAL in modern video standards?

VCL contains video coding layer data, such as coded slicer and picture content. NAL wraps coded data and parameter information into units suitable for storage or transport.

Non-VCL NAL units include sequence and picture parameter sets and supplemental information.

This separation lets networks, containers and decoders handle metadata and picture payloads cleanly.

• Vector excitation: chooses residual vector from codebook
• AbS: encoder is like a mini-decoder
• Closed loop shape search, and then transmits the optimal shape

Question: What is the role of the psychoacoustic masking model in perceptual audio coding and how is it used to allocate bits?

A psychoacoustic model estimates a frequency-dependent marking threshold. The encoder then allocates hits so quantization noise remains below those threshold when possible. Question: Explain what the MPD manifest is in DASH and how the client uses it to build segment requests.

Question: Explain how an ABR (Adaptive Bitrate) algorithm works: rate-based vs buffer-based logic, and the risk of overestimating available bandwidth.

ABR = Adaptive Bitrate

ABR Algorithm: client-side decision rule that chooses the bitrate of the next media segment.

Date-based: uses recent throughput estimates and chooses a representation below available bandwidth, often with a safety margin.

Buffer based: uses buffer occupancy. Low buffer→conservative bitrate, high buffer→higher bitrate. If band width is oversaturated, client requests segments too large to arrive on time, the buffer clears and holes occur.
