\subsubsection{Context-based coding}
Context-based coding predicts the probability of the next symbol from a causal neighborhood already known to both encoder and decoder. Better contexts lower coding rate when they make the next symbol more predictable, but excessively large contexts produce unreliable statistics.
It is based on context (near pixels), so joint probability.\\
How to choose the context? Look the data, or use learning-based techniques to learn prob. distribution.
\subsection{Other Techniques}
\subsubsection{Unsigned Exp-Golomb}
Unsigned Exp-Golomb is a universal variable-length code for non-negative integers. Small values receive short codewords, so it is effective for syntax elements and prediction residual magnitudes concentrated near zero.
\begin{minipage}{0.5\textwidth}
    \textbf{Encoder}:
    \begin{itemize}
        \item start with $n=0$
        \item $\forall n \in \{1,2,\cdots\}$ we write $n+1$ in binary
        \item we compute $b = \left\lfloor\log_2(n+1)\right\rfloor + 1$
        \item we add $b-1$ zeros in front of the binary number
    \end{itemize}
\end{minipage}
\begin{minipage}{0.5\textwidth}
    \textbf{Decoder}:
    \begin{itemize}
        \item if next bit is 1 $\to$ set to $0$
        \item count how leading zeros $(b-1)$ we have
        \item we read the $b$-sized bitstring
        \item we get the decimal representation and subtract 1
    \end{itemize}
\end{minipage}
\subsubsection{Signed Exp-Golomb}
Signed Exp-Golomb first maps positive and negative integers to non-negative integers, then applies unsigned Exp-Golomb coding. It preserves short codewords around zero without needing a separate sign bit.
\begin{minipage}{0.5\textwidth}
    \textbf{Encoder}:
    \begin{itemize}
        \item $m(n) = \begin{cases}
            2n-1 \qquad \text{if }n>0\\
            -2n \qquad \text{if }n\leq0
        \end{cases}$
        \item encode $m(n)$ with previous method
    \end{itemize}
\end{minipage}
\begin{minipage}{0.5\textwidth}
    \textbf{Decoder}:
    \begin{itemize}
        \item decode with unsigned exp-golomb
        \item remap $n = \begin{cases}
            \frac{m+1}{2} \qquad \text{if odd}\\
            -\frac{m}{2} \qquad \text{if even}\\
        \end{cases}$
    \end{itemize}
\end{minipage}
\subsubsection{Dictionary-based coding}
Dictionary-based coding replaces repeated symbol strings with references to entries in a shared dictionary. Its rate improves when long patterns recur, because one dictionary index can represent many source symbols.
\textbf{Asymptotic Optimality Theorem}:\\
If stationary and ergodic source, Dictionary-based coding is asymptotically optimal.\\
Examples of Dictionary-based coding: LZ\footnote{Lempel-Ziv}77, LZ78, LZW\footnote{Lempel-Ziv-Welsch} (used in Deflate, GIF, ZIP), LZMA.
\subsubsection{LZW coding}
LZW is an adaptive dictionary code in which encoder and decoder construct the same phrase dictionary while processing the stream. Only dictionary indexes are transmitted; the dictionary itself need not be sent.

\textbf{Encoder and Decoder - Greedy Matching Process + Dictionary Evolution and Merging}:
\begin{itemize}
    \item read inputstream symbol by symbol
    \item foreach new input, check if (prefix $W$ + next $K$) exists in the dictionary
    \item if $\exists \ (W+K)$, read next symbol until new pattern.
    \item if $\not\exists\ (W+K)$, index of longest known $W$ is sent to bitstream, $W+K$ added to dictionary
    \item then prefix merging and update local statistics
\end{itemize}
\subsubsection{Examples of real-life Coding}
\begin{itemize}
    \item JBIG-1: template of 10 pixels, progressive coding (context-based arithmetic coding).
    \item JBIG-2: images classified as text, halftone or other, it is used in PDFs, (context-based arithmetic coding).
    \item JPEG-LS: Lossless image compression, encoding\footnote{using Exp-Golomb} of $e = x - \hat{x}$, where $\hat{x} = \begin{cases}
        \min(A,B) \qquad C \geq \max(A,B)\\
        \max(A,B) \qquad C \leq \min(A,B)\\
        A+B-C \qquad \text{otherwise}
    \end{cases}$
    \item PNG: uses LZ77 + Huffman, not so difficult, can use prediction
    \item DPCM\footnote{Differential Pulse Coding Modulation}: 1D/2D spatial prediction, encodes error $y = x(n) - p(n) = x(n)-x(n-1)$ (zero-centered)
\end{itemize}
\subsubsection{Neural Lossless Coding (NLC) Techniques}
Neural lossless coding uses a neural probability model to estimate symbol distributions, then applies entropy coding without changing source values. Cross-entropy $H(P,Q)$ is the achieved ideal rate under model $Q$ when true data follow $P$; the KL term measures extra bits caused by model mismatch.
$$H(P,Q) = H(P) + D_{KL}(P\parallel Q)$$
It takes into account source entropy $H(P)$ and penalty for model inaccuracy based on Kullback-Leibler distance.\\%(how different are $P,Q$)
\textbf{Models}:
\begin{itemize}
    \item Autoregressive models: causal density estimation
    \item Latent Variable Models: mapping to manifolds
    \item Neural Predictive Coding (Non-linear prediction), uses multi-layer Perceptron
    $$\hat{y} = f_{MLP}(S,W)\to \text{INPUT S: local causal neighborhood}$$
\end{itemize}
NLC has an high complexity, is more efficient for high-resolution images. We also need to encode Biases and Weights, still convenient for small NNs but we also need HW requirements = complexity grows.
\subsubsection{Guidelines to reach $\mathcal{L} \approx \mathcal{H}$}
\begin{itemize}
    \item For Memoryless: use Huffman/Arithmetic
    \item For stationary with memory: use Context-adaptive (Markov Chains)
    \item For Locally Stationary: use adaptive
    \item For Highly Complex: use Neural Models
\end{itemize}
