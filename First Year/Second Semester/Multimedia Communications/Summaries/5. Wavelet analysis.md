## Introduction

### Signal Analysis through Projections

> [!Important] Universal Principle of Linear Transforms
> All transforms used in signal processing (DFT, DCT, Wavelet) are defined by **projection** of the input signal onto a set of basis functions.
>
> Given orthonormal basis $\{\phi_k(t)\}$, any signal $x(t)$ is represented as:
> $$x(t) = \sum_k c_k \cdot \phi_k(t)$$
> with coefficients:
> $$c_k = \langle x(t), \phi_k(t) \rangle = \int_{-\infty}^{+\infty} x(t) \cdot \phi_k^*(t)\, dt$$
>
> **Intuizione:** Large $|c_k|$ → high similarity between signal and basis function $k$. Transform = change of basis to achieve **energy compaction** (sparsity).

### Time-Frequency Uncertainty Principle

Consider $x[n] = \cos(\omega_0 n) \cdot \text{rect}_N[n]$. As window length $N$ changes:

| Window size | Time localization $\Delta t$ | Frequency resolution $\Delta f$ |
|-------------|------------------------------|----------------------------------|
| Short ($N=16$) | Excellent | Poor (blurry peak) |
| Medium ($N=32$) | Good | Improving |
| Long ($N=64$) | Poor | Good |
| Very long ($N=128$) | Very poor | Excellent |

> [!Important] Heisenberg-like Uncertainty Principle
> $$\Delta t \cdot \Delta f \geq \frac{1}{4\pi}$$
> The **area** of the uncertainty cell in the time-frequency plane is **constant**. We can only change the shape (narrow/tall vs wide/flat), never reduce both simultaneously.

### STFT and Rigid Tiling

Standard transforms (e.g., JPEG's Block-DCT) use **fixed window size** for all frequencies → **rigid tiling** of the time-frequency plane.

Problem: once $N$ is chosen, resolution is constant. Natural signals contain both fast transients (require small $N$) and precise frequencies (require large $N$).

![[Pasted image 20260522131505.png]]

### Wavelets: Adaptive Multiresolution

Wavelets solve the trade-off by **adapting the window shape** to the frequency:

- **High frequencies:** short windows → fine time resolution → catch edges/anomalies
- **Low frequencies:** long windows → fine frequency resolution → catch trends/textures

![[Pasted image 20260522131525.png]]

**Biological link:** matches human visual and auditory system processing.

**Mechanism — shift and dilation:** single **mother wavelet** $\psi(t)$ generates basis via scaling and translation:

$$\psi_{a,b}(t) = \frac{1}{\sqrt{a}} \psi\left(\frac{t-b}{a}\right)$$

Using the Fourier scaling property ($\mathcal{F}\{x(t/a)\} = |a|X(af)$):
- **Large $a$ (dilation):** stretches in time, shrinks in frequency → lower frequencies, finer $\Delta f$
- **Small $a$ (compression):** shrinks in time, stretches in frequency → higher frequencies, finer $\Delta t$

### Image Model: Trends and Anomalies

| Component     | Signal character  | Frequency | Feature                | Resolution needed             |
| ------------- | ----------------- | --------- | ---------------------- | ----------------------------- |
| **Trends**    | Slow variations   | Low       | Object texture         | Rough spatial, fine frequency |
| **Anomalies** | Abrupt variations | High      | Object contours, edges | Fine spatial, rough frequency |

## Discrete Wavelet Transform and Multiresolution Analysis

### 1D Filter Banks

**Analysis (decomposition):**

$$x[k] \xrightarrow{h_0[\cdot]} \tilde{c}[k] \xrightarrow{\downarrow 2} c[k]$$
$$x[k] \xrightarrow{h_1[\cdot]} \tilde{d}[k] \xrightarrow{\downarrow 2} d[k]$$

- $h_0$: **low-pass filter** → approximation coefficients $c[k]$
- $h_1$: **high-pass filter** → detail coefficients $d[k]$
- **Decimation ($\downarrow 2$):** $c[k] = \tilde{c}[2k]$ (keep every other sample)

**Synthesis (reconstruction):**

$$c[k] \xrightarrow{\uparrow 2} \hat{c}[k] \xrightarrow{f_0[\cdot]} \bar{x}[k]$$
$$d[k] \xrightarrow{\uparrow 2} \hat{d}[k] \xrightarrow{f_1[\cdot]} \bar{x}[k]$$

- **Interpolation ($\uparrow 2$):**
$$\hat{c}[k] = \begin{cases} c[k/2] & \text{if } k \text{ even} \\ 0 & \text{if } k \text{ odd} \end{cases}$$

**Desirable filter properties:**
1. **Perfect Reconstruction (PR)**
2. **FIR** (finite impulse response)
3. **Orthogonality** (energy conservation)
4. **Vanishing moments** (sparsity)
5. **Symmetry** (linear phase, no distortion)

*(nota: these properties cannot all be simultaneously satisfied for non-trivial filters — a fundamental trade-off)*

### Z-Domain Relationships

Key Z-domain relationships for the analysis-synthesis chain:

$$\tilde{C}(z) = H_0(z)X(z) \quad \text{(filtering)}$$
$$C(z) = \frac{1}{2}\left[\tilde{C}(z^{1/2}) + \tilde{C}(-z^{1/2})\right] \quad \text{(decimation)}$$
$$\hat{C}(z) = C(z^2) \quad \text{(interpolation)}$$

Output of synthesis bank:
$$\tilde{X}(z) = F_0(z)C(z^2) + F_1(z)D(z^2)$$

Expanding:
$$\tilde{X}(z) = \underbrace{\frac{1}{2}\left[F_0(z)H_0(z) + F_1(z)H_1(z)\right]}_{\text{signal term}} X(z) + \underbrace{\frac{1}{2}\left[F_0(z)H_0(-z) + F_1(z)H_1(-z)\right]}_{\text{aliasing term}} X(-z)$$

### Perfect Reconstruction Conditions

> [!Important] PR Conditions in Z-domain
> **No distortion (ND):**
> $$T(z) = H_0(z)F_0(z) + H_1(z)F_1(z) = 2z^{-\ell}$$
>
> **Aliasing cancellation (AC):**
> $$A(z) = H_0(-z)F_0(z) + H_1(-z)F_1(z) = 0$$
>
> Together: $\tilde{X}(z) = z^{-\ell}X(z)$ (pure delay — perfect reconstruction).

**Matrix form:** given analysis filters, synthesis filters determined by:

$$\begin{bmatrix} H_0(z) & H_1(z) \\ H_0(-z) & H_1(-z) \end{bmatrix} \begin{bmatrix} F_0(z) \\ F_1(z) \end{bmatrix} = \begin{bmatrix} 2z^{-\ell} \\ 0 \end{bmatrix}$$

Requires invertibility of modulation matrix:
$$\forall z \in \mathbb{C}, |z|=1: \quad \Delta(z) = H_0(z)H_1(-z) - H_1(z)H_0(-z) \neq 0$$

### Orthogonality

**QMF** (*Quadrature Mirror Filters*) and **CQF** (*Conjugate Quadrature Filters*) are orthogonal → **energy conservation:**

> [!Important] Energy Conservation (Orthogonal Filterbank)
> $$\sum_{k=-\infty}^{\infty} (x_k)^2 = \sum_{k=-\infty}^{\infty} (c_k)^2 + \sum_{k=-\infty}^{\infty} (d_k)^2$$
>
> **Consequence:** reconstruction error = quantization error on DWT coefficients (no additional noise from the transform itself).

For **biorthogonal filters:** reconstruction error = weighted sum of quantization errors across DWT subbands with weights $\omega_i$.

![[PLACEHOLDER_Fig_6 — Orthogonality illustration: energy split between approximation and detail subbands is lossless.]]

### Vanishing Moments

**Vanishing moments (VM):** filter's ability to reproduce polynomials.

> [!Important] Vanishing Moments Property
> A filter with $p$ **vanishing moments** can represent polynomials of degree $< p$.
> The high-pass filter will **not respond** to a polynomial input of degree $< p$ → all signal information is preserved in the approximation.
> A filter with $p$ VM has **at least $2p$ taps**.

![[PLACEHOLDER_Fig_7 — Vanishing moments: a high-pass filter with p VM produces zero output for polynomial input of degree < p. Shows sparse detail coefficients for smooth regions.]]

**Compression benefit:** smooth regions → few non-zero detail coefficients → high sparsity.

### Border Problem

Filter bank properties are valid for **infinite-size signals**; images are finite-support signals.

**Problem:** linear convolution of $N$-sample signal with $M$-tap filter → output of $N+M-1$ samples (coefficient expansion).

Three solutions:

1. **Zero padding:** causes coefficient expansion — unusable.

2. **Periodization (circular convolution):**
   - Signal $x$ of support $N$ treated as periodic with period $N$
   - Output has same period $N$ → only $N$ coefficients needed
   - Problem: introduces **discontinuities ("jumps")** at boundaries → spurious high-frequency coefficients

   ![[PLACEHOLDER_Fig_8 — Periodization: signal extended periodically. Shows artificial jump at boundary causing spurious coefficients in HP subband.]]

3. **Symmetrization:**
   - Symmetrize signal before periodization → removes discontinuities
   - Problem: doubles the number of coefficients (period $2N$)
   - Solution: if **filters are also symmetric**, output $\tilde{y}_s$ is periodic and symmetric with period $2N$ → only $N$ unique samples needed

   ![[PLACEHOLDER_Fig_9 — Symmetrization: signal mirrored before periodization eliminates boundary discontinuity. With symmetric filters, coefficient count remains N.]]

> [!Important] Fundamental Constraint
> **The only orthogonal, symmetric, FIR filter is the Haar filter.**
>
> For compression, symmetry (avoids frequency leaking) is more important than orthogonality → use **biorthogonal filters** instead.

### Haar Filter

$$h_0(k) = \begin{bmatrix} 1 & 1 \end{bmatrix}, \quad f_0(k) = \begin{bmatrix} 1 & 1 \end{bmatrix}$$
$$h_1(k) = \begin{bmatrix} 1 & -1 \end{bmatrix}, \quad f_1(k) = \begin{bmatrix} -1 & 1 \end{bmatrix}$$

Properties:
- Symmetric ✓
- Orthogonal (both QMF and CQF) ✓
- VM = 1 (only represents piecewise constant signals)
- Minimal: 2 taps
### Biorthogonal Filters: CDF

**Cohen-Daubechies-Fauveau (CDF) filters** — the standard in image compression:

> [!Important] CDF Biorthogonal Filters
> If analysis filter $h_0$ has $p$ VM and synthesis $f_0$ has $\tilde{p}$ VM, filter has at least $p + \tilde{p} - 1$ taps.
>
> CDF properties:
> - **Symmetric** (linear phase)
> - **Maximize VM** for given filter length
> - **Near-orthogonal** (weights $\omega_i \approx 1$)

**Standard filters in image compression:**

| Filter | VM | Taps | Properties | Use |
|--------|-----|------|-----------|-----|
| **Daubechies 9/7** | 4 | 9/7 | Best R-D performance | JPEG2000 lossy |
| **Daubechies 5/3** | 2 | 5/3 | Integer-valued taps → exact reconstruction | JPEG2000 lossless |

![[PLACEHOLDER_Fig_11 — CDF 9/7 and 5/3 filter coefficients. Symmetric filter responses shown.]]

### 2D Adaptive Multiresolution

**Separable 2D transform:** apply 1D filter bank along rows then along columns.

One decomposition level of image $c_j[n,m]$ produces 4 subbands:

| Subband | Operation | Content |
|---------|-----------|---------|
| **LL** ($c_{j+1}$) | LP rows + LP cols | Low-res approximation |
| **HL** ($d_{j+1}^V$) | HP rows + LP cols | Vertical details (horizontal edges) |
| **LH** ($d_{j+1}^H$) | LP rows + HP cols | Horizontal details (vertical edges) |
| **HH** ($d_{j+1}^D$) | HP rows + HP cols | Diagonal details |

![[Pasted image 20260522133023.png]]

**Recursive application:** LL subband decomposed again → multi-level 2D-DWT tree.

### Choosing Number of Decomposition Levels

**Optimal: 4 to 6 levels** for 2D-DWT.

Reasons why more levels become ineffective:
- LL subband becomes too small → new level impacts very few coefficients
- Low-resolution subband loses spatial smoothness → trends+anomalies model no longer valid → transform doesn't improve sparsity

## Image Compression with Wavelets

Two families:

| Family | Mechanism | Advantages | Disadvantages |
|--------|-----------|-----------|---------------|
| **Inter-scale** (EZW, SPIHT) | Tree-based inter-scale dependencies | Good inter-scale exploitation, low complexity | No resolution scalability |
| **Intra-scale** (subband allocation) | Explicit rate allocation + entropy coding | Good intra-scale exploitation, random access, resolution scalability | No inter-scale exploitation |

### EZW: Embedded Zerotrees of Wavelet Coefficients

**Main characteristics:**
- **Quality scalability** (progressive representation)
- **Lossy-to-lossless** coding
- Low complexity
- R-D performance much better than JPEG, especially at low rates

#### Progressive Representation

To minimize distortion at any intermediate bit budget:
- Send **largest coefficients first** (each bit conveys maximum information)
- Problem: need to signal position (localization overhead)
- Solution: exploit **inter-scale correlation** to predict significance

#### Zero-Tree Structure

> [!Important] Zero-Tree (ZT) Definition
> Each coefficient in the DWT tree has:
> - Root at LL subband (3 descendants in first-level detail subbands)
> - From level 2 onward: 4 descendants (co-located coefficients in same orientation subband at next resolution level)
>
> **Auto-similarity principle:** if a coefficient is small (below threshold $T$), its descendants are likely small too.
>
> A **(sub-)tree of below-threshold coefficients** = **zero-tree**.
>
> Encoding an entire zero-tree with **one symbol (ZR)** saves $(1 + 4 + 4^2 + \ldots + 4^{N-n})$ individual codes.

![[PLACEHOLDER_Fig_21 — Zero-tree structure: parent-child relationships across DWT scales. Root in LL2, descendants in same orientation (HL/LH/HH) at finer scales. A zero-tree root and its all-insignificant subtree shown.]]

**Four symbols:**
- **SP** (Significant Positive): $c \geq T$
- **SN** (Significant Negative): $c \leq -T$
- **IZ** (Isolated Zero): $|c| < T$ but has at least one descendant with $|c| \geq T$
- **ZR** (Zero-tree Root): $|c| < T$ and all descendants $< T$

#### EZW Algorithm

```
k = 0
n = floor(log2(max|c|))
T_k = 2^n
L = list of all DWT coefficients (subband scan order, each SB in raster scan)
S = {} (significant coefficients)

while rate < available_rate:
    Dominant Pass
    Refining Pass
    T_{k+1} = T_k / 2
    k = k + 1
```

**Dominant Pass:**
```
For each c in L:
    if c >= T_k:   encode SP, add c to S
    elif c <= -T_k: encode SN, add c to S
    elif no descendant |c| >= T_k: encode ZR, remove all descendants from L
    else: encode IZ
    remove c from L
```

**Refining Pass:**
```
b = log2(T_k)   (current bitplane index)
For each c in S:
    encode the b-th bit of |c|'s binary representation
```

**Iteration:** threshold halves each iteration ($T_{k+1} = T_k/2$) → equivalent to moving to next bitplane. Stop when bit budget exhausted or all bitplanes coded.

> [!Example] EZW Encoding — 4×4 Matrix Example
> **Input DWT coefficients:**
> $$\begin{bmatrix} 26 & 6 & -13 & 10 \\ -7 & 3 & 6 & 4 \\ 4 & -3 & 3 & -3 \\ 2 & -2 & -2 & 0 \end{bmatrix}$$
>
> **Bitplane 1 ($T=16$, $n=4$):**
> - Dominant: $|26|=26 \geq 16$ → **SP**; $|6|=6 < 16$, all descendants $\{-13, 10, 6, 4\} < 16$ → **ZR**; $-7$, $3$ also **ZR**
> - Symbol stream: `[SP, ZR, ZR, ZR]`
> - Refining: $26_{10} = 11010_2$ → bit 4 = **1**
> - Stream: `[SP, ZR, ZR, ZR | 1]`
>
> **Bitplane 2 ($T=8$):**
> - Dominant: $6 < 8$ but descendant $13 \geq 8$ → **IZ**; $-7, 3$ → **ZR**; $|-13|=13 \geq 8$ → **SN**; $|10|=10 \geq 8$ → **SP**; remaining < 8 → **ZR**
> - Stream: `[SP,ZR,ZR,ZR | 1 | IZ,ZR,ZR,SN,SP,ZR,ZR]`
> - Refining: $26 \to 0$, $13 \to 1$, $10 \to 0$
> - Stream: `[...|0,1,0]`
>
> **Bitplane 3 ($T=4$):**
> - Dominant: $6 \geq 4$ → SP, $-7 \leq -4$ → SN, $3 < 4$ → ZR; then $6,4,4$ → SP; rest → ZR
> - Refining: bits for all 8 significant coefficients (26→1, 13→0, 10→1, 6→1, 7→1, 6→1, 4→0, 4→0)
>
> **Result:** symbol stream encodes all coefficients progressively, largest first.

#### EZW Decoding

Decoder maintains current estimate of each significant coefficient:
- On **SP/SN**: knows MSB → initial estimate = center of uncertainty interval $[T, 2T)$, i.e., $T + T/2 = 3T/2$
- Each refining bit: narrows interval by factor 2 → midpoint update

> [!Example] EZW Decoding — Step by Step
> **After Dominant Pass 1 ($T=16$):** receive SP at [1,1]. MSB known: $1xxxx_2$. Estimate = midpoint of $\{10000_2 \ldots 11111_2\} = 11000_2 = 24$.
>
> **After Refining Pass 1:** receive bit=1. Value now $11xxx_2$. Estimate = midpoint of $\{11000_2 \ldots 11111_2\} = 11100_2 = 28$.
>
> **After Dominant Pass 2 ($T=8$):** receive SN at [1,3]. Estimate = $-01100_2 = -12$.
>
> **After Refining Pass 2:** bits [0,1,0] → 26 becomes 26, -13 becomes -14, 10 stays 10.
>
> Progressive convergence to true values as more bitplanes decoded.

**Properties:**
- **Bitplane coding:** $k$-th pass encodes bitplane $\log_2 T_k$
- **Quality scalability:** decoder can stop at any point → graceful quality degradation
- **Lossless:** with integer DWT (Daubechies 5/3) and all bitplanes coded → zero distortion

### JPEG2000

Designed to address JPEG limitations:

| Problem with JPEG | JPEG2000 Solution |
|-------------------|------------------|
| Low quality at $R < 0.25$ bpp | Better wavelet transform |
| Poor for synthetic images | Global transform (no 8×8 blocking) |
| No random access | Tiling + codeblock independence |
| No scalability | Quality and resolution scalability |

**New functionalities:**
- **ROI (Region of Interest) coding:** allocate more bits to important regions
- **Quality and resolution scalability**
- **Tiling:** independent processing of image regions
- **Exact coding rate:** target bitrate achieved with < 0.1% error
- **Lossy-to-lossless coding**

#### Algorithm Structure

**Tier 1:**
1. 2D-DWT (Daubechies 9/7 for lossy, 5/3 for lossless)
2. (Optional) uniform quantization with fine step
3. Lossless arithmetic coding of codeblocks (bitplane by bitplane)

**Tier 2:**
- EBCOT: *Embedded Block Coding with Optimized Truncation*
- Manages scalability (quality, resolution) and ROI

**Quantization note:** actual lossy operations performed by **bitstream truncation** in Tier 2, not by quantization step. Quantization is very fine (near-lossless); lossless case uses integer DWT with no quantization.

---

### EBCOT

*Embedded Block Coding with Optimized Truncation*

**Structure:**
- Each DWT subband split into equally-sized **codeblocks** (e.g., 64×64)
- Each codeblock independently arithmetically coded → separate **bitstream**
- Each bitstream partitioned by **bitplane** (3 coding passes per bitplane)
- Result after Tier 1: one bitstream per codeblock, each partitioned into fine segments

![[PLACEHOLDER_Fig_22 — EBCOT codeblock organization: each subband divided into blocks; each block produces an independent bitstream partitioned by bitplane passes.]]

#### Rate-Distortion Optimization

After Tier 1, we know the R-D curve $D_i(R_i)$ for each codeblock $i$.

**Problem:** how to truncate bitstreams to minimize total distortion at target rate?

$$\min \sum_i D_i \quad \text{subject to} \quad \sum_i R_i \leq R_{\text{tot}}$$

**Solution — Lagrange multiplier:**

$$J = \sum_i \left(D_i + \lambda R_i\right) - \lambda R_{\text{tot}}$$

> [!Important] EBCOT Optimal Truncation Condition
> Optimal truncation point $R_i^*$ for block $i$ satisfies:
> $$\frac{\partial J_i}{\partial R_i} = \frac{\partial D_i}{\partial R_i} + \lambda = 0$$
>
> At optimum: **all codeblocks have the same slope** $\partial D_i / \partial R_i = -\lambda$ on their R-D curves.
>
> $\lambda$ found by iterative algorithm. Multiple $\lambda$ values → multiple truncation points → **quality layers**.

![[PLACEHOLDER_Fig_23 — R-D curves for multiple codeblocks. Optimal truncation: vertical line at rate where all curves have slope = -λ. Different codeblocks truncated at different bitplane levels.]]

**Quality scalability:** compute truncation points for several target rates → organize bitstream into **quality layers** (each layer = one color in the bit allocation diagram). Syntax markers separate layers in bitstream.

**Resolution scalability:** can also allocate bits only to LL subband → minimal resolution, maximum quality for that subband.

![[PLACEHOLDER_Fig_24 — Bit allocation diagram: columns=codeblocks, rows=bitplane passes. Colored regions show which passes are included at each target rate. Different rate targets produce different "staircases" of included passes.]]

### Error Robustness

**Problem with compressed streams:** bit errors have catastrophic impact:
- **Predictive/differential coding** → error propagation
- **Variable-length coding** → decoding drift
- **Header errors** → entire file corrupted

**Strategies:**
- **Error correction codes** (ECC): highly effective but costly → used only for headers/metadata
- **Resynchronization markers:** inserted periodically into bitstream → stop error propagation. More frequent markers = better robustness but larger file + requires **bit stuffing** (marker emulation prevention)

**JPEG2000 vs JPEG robustness:**

| Feature | JPEG | JPEG2000 |
|---------|------|---------|
| Codeblock independence | No (global entropy stream) | Yes (each block independent) |
| Error propagation | Severe | Contained within one codeblock |
| Transform | Block-based (8×8) → blocking artifacts | Global DWT → no blocking |
