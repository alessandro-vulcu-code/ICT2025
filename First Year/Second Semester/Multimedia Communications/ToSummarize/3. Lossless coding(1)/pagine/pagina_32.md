Binary variable entropy

Case of binary RV
Alphabet: {0,1}
The probability mass function (pmf) is given by:

$$p = P\{X = 0\}$$
$$q = P\{X = 1\} = 1 - p \quad \text{as a consequence}$$
$$H(X) = -p \log(p) - (1 - p) \log(1 - p)$$

The entropy can be traced as a function of a single parameter $p$
