▶ Problem formulation
▶ Given a set of $M$ symbols with probabilities $p_i$
▶ Find the set of $M$ lenghts $\ell_i$ such that:
  ▶ $\forall i = 1, \ldots, M, \ell_i \in \mathbb{N}$
  ▶ The Kraft's inequality is satisfied (prefix code)
