Example: building a prefix code

Let us build a code with lengths $\{1, 2, 3, 3\}: 2^{-1} + 2^{-2} + 2^{-3} + 2^{-3} = 1$

Select an available leaf. The code is $\{0, 10, 110, 111\}$

Conclusion: Lengths satisfying Kraft’s inequality $\Rightarrow$ we can build a prefix code with those lengths.
