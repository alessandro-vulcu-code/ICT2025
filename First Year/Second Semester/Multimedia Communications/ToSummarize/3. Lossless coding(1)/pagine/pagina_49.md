Shannon’s source coding theorem

The minimum average lenght $\mathcal{L}^* = H(X)$ can be achieved if and only if the lenghts are dyadic:

$$\forall i \in \{1, 2, \ldots M\}, \exists k \in \mathbb{N} \mid p_i = 2^{-k}$$

Therefore, in the general case, the average lenght can only be greater than or equal to the entropy:

$$\mathcal{L}^* \geq H(X)$$

with equality if and only if the lenghts are dyadic

This is the Shannon’s Source Coding Theorem
