## Definitions

### What is quantization?

Quantization is the process of mapping a signal taking values in a continuous (or large discrete) set to a signal that can take only a finite number of values.

- Used to represent analog or high-precision digital signals with fewer bits
- Fundamental operation in any lossy compression system
- Introduces irreversible information loss (distortion)

### Quantizer model

A quantizer $Q$ is defined by:

- **Thresholds**: $-\infty = t^0 < t^1 < t^2 < \ldots < t^{L-1} < t^L = +\infty$
- **Quantization regions**: $\Theta^i = [t^{i-1}, t^i)$ for $i = 1, \ldots, L$
- **Reconstruction levels (dictionary)**: $\hat{x}^1, \hat{x}^2, \ldots, \hat{x}^L$

The quantizer maps $x \in \Theta^i$ to $Q(x) = \hat{x}^i$.

### Scalar quantizer

A **scalar quantizer** (SQ) operates on one sample at a time:

$$\tilde{X} = Q(X)$$

The encoding operation maps each input value to an index $k \in \{1, \ldots, L\}$. The decoding operation maps each index to a reconstruction level $\hat{x}^k$.

### Quantization error

The quantization error (or noise) is:

$$e = X - Q(X) = X - \tilde{X}$$

### Distortion

The most common distortion measure is the Mean Square Error (MSE):

$$D = \sigma_Q^2 = \mathrm{E}\left[(X - Q(X))^2\right]$$

### Rate

The rate of a scalar quantizer with $L$ levels is:

$$R = \log_2 L \quad \text{[bits/sample]}$$

### Types of quantizers

- **Uniform quantizer (UQ)**: all quantization regions have the same width $\Delta$
- **Non-uniform quantizer**: regions have variable width, adapted to the PDF of the input

### Granular noise and overload noise

Two regimes of quantization error:

- **Granular noise**: input $x$ falls inside the dynamic range. Error is bounded: $|e| \leq \Delta/2$
- **Overload (clipping) noise**: input $x$ falls outside the dynamic range $[-A/2, A/2]$. Error can be arbitrarily large

### SNR

The Signal-to-Noise Ratio is:

$$\mathrm{SNR} = 10\log_{10}\frac{\mathrm{E}\{X^2\}}{D} = 10\log_{10}\frac{\sigma_X^2}{\sigma_Q^2} \quad [\mathrm{dB}]$$

## Uniform Quantization

### Definition

A **uniform quantizer** (UQ) partitions the dynamic range $[-A/2, A/2]$ into $L$ equal intervals of width:

$$\Delta = \frac{A}{L} = A \cdot 2^{-R}$$

Reconstruction levels are placed at the center of each interval:

$$\hat{x}^i = -\frac{A}{2} + \left(i - \frac{1}{2}\right)\Delta, \quad i = 1, \ldots, L$$

### Midrise and midtread

[Figura: Funzione a scalini del quantizzatore uniforme, con due varianti: midrise (L pari, nessun livello in zero) e midtread (L dispari, livello in zero)]

- **Midtread**: includes a zero output level ($L$ odd)
- **Midrise**: no zero output level ($L$ even); more common in practice

### Quantization formula

For a midrise uniform quantizer:

$$Q(x) = \Delta \cdot \left\lfloor \frac{x}{\Delta} + \frac{1}{2} \right\rfloor$$

with saturation at $\pm A/2$.

### Step size and clipping tradeoff

- Small $\Delta$ (large $L$): fine quantization, low granular noise, but fixed $A$ may cause more clipping for signals with high peaks
- Large $\Delta$ (small $L$): coarse quantization, high granular noise, but wide dynamic range

### Dynamic range choice

The dynamic range $A$ must be adapted to the signal statistics:

- Too small $A$: frequent clipping, high distortion
- Too large $A$: fine quantization wasted, increased granular noise for a given bit budget

## Rate-distortion curve

### Probability Theory Refreshers

**1. Uniform Random Variable**

A continuous random variable $X$ is said to be **uniformly distributed** on the interval $[a, b]$ if its Probability Density Function (PDF) is defined as:

$$X \sim \mathcal{U}(a, b) \Leftrightarrow f_X(x) = \begin{cases} \frac{1}{b-a} & \text{for } a \leq x \leq b \\ 0 & \text{otherwise} \end{cases}$$

Its variance is $\mathrm{Var}(X) = \frac{(b-a)^2}{12}$

**2. Expected Value of a Function of an R.V. (LOTUS)**

Let $X$ be a continuous random variable with PDF $f_X(x)$. The expected value of a real-valued function $g(X)$ is given by:

$$E[g(X)] = \int_{-\infty}^{+\infty} g(x) f_X(x) \, dx$$

This theorem (Law of the Unconscious Statistician) allows us to calculate the mean of $g(X)$ without first finding its own PDF.

### Uniform Quantization: RD curve

Let us apply these results to find the distortion of a uniform RV quantized with UQ.

**Hypotheses**: $X \sim \mathcal{U}\!\left(-\frac{A}{2}, \frac{A}{2}\right)$ and $Q(x)$ is a uniform quantizer with $L$ levels.

**Goal**: Find $\sigma_Q^2 = \mathrm{E}\!\left[(X - \tilde{X})^2\right]$ as a function of $A$, $L$.

We observe that $\sigma_Q^2 = \mathrm{E}[g(X)]$, where $\forall u \in \mathbb{R},\, g(u) = (u - Q(u))^2$.

$$\sigma_Q^2 = \mathrm{E}\!\left[(X - \tilde{X})^2\right] = \int_{-\infty}^{+\infty} p_X(u)[u - Q(u)]^2 \, du$$

$$\ldots = \sum_{i=1}^{L} \int_{\Theta_i} \frac{1}{A}[u - \hat{x}^i]^2 \, du = \frac{1}{A} \sum_{i=1}^{L} \int_{\hat{x}^i - \Delta/2}^{\hat{x}^i + \Delta/2} [u - \hat{x}^i]^2 \, du$$

$$= \frac{1}{A} \sum_{i=1}^{L} \int_{-\Delta/2}^{\Delta/2} t^2 \, dt = \frac{1}{A} \cdot \frac{\Delta^3}{12} = \frac{\Delta^2}{12} = \frac{1}{12} \cdot \frac{A^2}{L^2}$$

We can use the previous result to determine the **rate-distortion** curve of the UQ, i.e. the mathematical relationship between the rate $R$ and the distortion $D = \sigma_Q^2$:

$$D = \frac{\Delta^2}{12} = \frac{A^2}{12L^2} = \frac{A^2/12}{2^{2R}} = \sigma_X^2 \cdot 2^{-2R}$$

$$\mathrm{SNR} = 10\log_{10} \frac{\mathrm{E}\{X^2\}}{D} = 10\log_{10} \frac{\sigma_X^2}{\sigma_X^2 \cdot 2^{-2R}} = 10\log_{10} 2^{2R} \approx 6R$$

### High Resolution (HR) Uniform Quantization

- **Hypothesis**: $L \to +\infty$, $X$ generic RV
- In HR, in any given $\Theta^i$ we can approximate $p_X$ as a constant (it is constant in the region, but the value can be different in another region)
- Therefore, the quantization noise in $\Theta^i$ is $\mathcal{U}\!\left(-\frac{\Delta}{2}, \frac{\Delta}{2}\right)$
- From the total probability law, $E \sim \mathcal{U}\!\left(-\frac{\Delta}{2}, \frac{\Delta}{2}\right)$
- Thus:

$$D = \frac{\Delta^2}{12} = \frac{A^2}{12} \cdot 2^{-2R}$$

$$\mathrm{SNR} = 10\log_{10} \frac{\mathrm{E}\{X^2\}}{D} = 10\log_{10} \frac{\sigma_X^2}{A^2/12 \cdot 2^{2R}} \approx 6R - 10\log_{10} \frac{\gamma^2}{3}$$

where $\gamma^2 = \frac{X^2_{\max}}{\sigma_X^2} = \frac{A^2/4}{\sigma_X^2}$ is the **load factor**, i.e. the ratio between the peak power and the average power.

$$D = \frac{A^2}{3} \cdot 2^{-2R} = \frac{\gamma^2}{3} \sigma_X^2 \cdot 2^{-2R} = K_X \sigma_X^2 \cdot 2^{-2R}$$

## Optimal Scalar Quantization

### Optimal quantization

For a given probability density function $p_X(x)$, we want to find the quantizer minimizing distortion for a given rate. Problem equivalent to determine thresholds $t^i$ and levels $\hat{x}^i$.

Solutions:

- Analytic Solution in **high resolution**: $D = c_X \sigma_X^2 \cdot 2^{-2R}$
- If the high resolution hypothesis is not met, we can find a local optimum with the **Lloyd-Max algorithm**

### Optimal quantization in high resolution

- The optimal quantizer is the one that, for a given PDF $p_X$ of the input samples, provides the least distortion $D = \mathrm{E}\!\left[(X - Q(X))^2\right]$ for a given rate $R$
- It is possible to find the rate-distortion curve for the optimal quantizer in the **high-resolution hypothesis**:
  - $L \to \infty$
  - $\max_i \Delta_i \to 0$
  - $\forall i, \forall u \in \Theta^i,\; p_X(u) \approx P_i$
- Then it can be shown that the optimal quantizer has the following RD curve:

$$\sigma_Q^2 = c_X \sigma_X^2 \cdot 2^{-2R} \qquad \text{with} \qquad c_X = \frac{1}{12}\left[\int_{\mathbb{R}} p_U^{1/3}(t)\, dt\right]^3 \qquad \text{and} \qquad U = \frac{X}{\sigma_X}$$

### Shape Factor

In the RD curve of the optimal quantizer $\sigma_Q^2 = c_X \sigma_X^2 \cdot 2^{-2R}$, the term $c_X$ is called **shape factor**, since it only depends on the PDF shape, and not on its variance. The shape of $X$ is obviously the same as of $U$.

Shape factors for common PDFs:

| | Uniform | Gaussian |
|-|---------|----------|
| $c_X$ | $1$ | $\frac{\sqrt{3}}{2}\pi \approx 2.72$ |

### Non-HR Optimal quantization

- High resolution hypothesis is not always met
- On the contrary, often quantization must work at low or very low rate
- **There is no analytical solution for low resolution optimal quantization**
- On the other hand, it is possible to find **necessary conditions** for optimal quantizers independently from the resolution
- These conditions allows to define an algorithm attaining a local optimum point (Lloyd-Max algorithm)

### Optimal quantization: Lloyd-Max algorithm

**Lloyd-Max algorithm**

1. Choose an initial dictionary $\mathcal{C}^{(0)} = \{\hat{x}^i_0\}_{i=1,\ldots,L}$
2. Find the **best** thresholds for the given dictionary
3. Find the **best** dictionary for the given thresholds
4. Iterate 2–3 until a stop condition is met

### Lloyd-Max algorithm: initial dictionary

- **Uniform Initialization**: $\hat{x}^n = -A_0 + n\Delta \; \forall n = 1, \ldots, L$
- **Random Initialization**: code-words are initialized with the same distribution as data

### Lloyd-Max algorithm: nearest neighbor rule

Given $\{\hat{x}^i\}_{i=1,\ldots,L}$, we have to define, for each input, which is the best level to use as its representative. The best choice is obviously the nearest neighbor:

$$k = \arg\min_n |x - \hat{x}^n| \Rightarrow Q(x) = \hat{x}^k$$

Choosing the next neighbor is equivalent to set the threshold at the midpoint between consecutive quantization levels:

$$t^i = \frac{\hat{x}^i + \hat{x}^{i+1}}{2}, \quad i \in \{1, \ldots, L-1\}$$

### Lloyd-Max algorithm: centroid condition

Given the thresholds $\{t^0, \ldots, t^L\}$, the best levels are those minimizing the distortion:

$$\sigma_Q^2 = \sum_{i=1}^{L} \int_{t^{i-1}}^{t^i} (u - \hat{x}^i)^2 p_X(u)\, du$$

To find the optimal levels, we compute the gradient of the distortion and set it to 0:

$$\frac{\partial \sigma_Q^2}{\partial \hat{x}^i} = \frac{\partial}{\partial \hat{x}^i} \int_{t^{i-1}}^{t^i} (u - \hat{x}^i)^2 p_X(u)\, du = \int_{t^{i-1}}^{t^i} \frac{\partial}{\partial \hat{x}^i} (u - \hat{x}^i)^2 p_X(u)\, du$$

$$= \int_{t^{i-1}}^{t^i} 2(\hat{x}^i - u) p_X(u)\, du = 2\hat{x}^i \int_{t^{i-1}}^{t^i} p_X(u)\, du - 2\int_{t^{i-1}}^{t^i} u\, p_X(u)\, du$$

$$\hat{x}^i = \frac{\int_{t^{i-1}}^{t^i} u\, p_X(u)\, du}{\int_{t^{i-1}}^{t^i} p_X(u)\, du} = \frac{\int_{\Theta_i} u\, p_X(u)\, du}{\int_{\Theta_i} p_X(u)\, du} = \mathrm{E}\left[X \mid X \in \Theta^i\right]$$

This is the so-called **centroid condition**: the best representative of a quantization region is its centroid, i.e. the conditional average of $X$ given $X \in \Theta^i$.

### Lloyd-Max algorithm: stop condition

- After the $k$-iteration of NN and the centroid rules, we can compute the new distortion value $\sigma^2_{Q,(k)}$
- It can be compared with the previous distortion $\sigma^2_{Q,(k-1)}$; the optimization steps assure that the new distortion can only be less than or equal to the old one
- We compute the relative distortion reduction: if it is smaller than a threshold, we stop the algorithm:

$$\frac{\sigma^2_{Q,(k-1)} - \sigma^2_{Q,(k)}}{\sigma^2_{Q,(k-1)}} < \varepsilon$$

- Another stop condition is upon a given number of iterations: $k = K$

### Convergence of Lloyd-Max algorithm

- Convergence to global optimum is **not assured**
- Final result depends on **initialization**
- However, at each step distortion cannot increase

### Lloyd-Max algorithm for data

In real-life problems, we have not signal PDFs, but rather a bunch of data. We can modify Lloyd-Max algorithm as follows:

1. Let $\mathcal{X} = \{u_1, u_2, \ldots, u_M\}$ be the set of data to quantize (or the training set if data is not known in advance)
2. Initialize ($k=0$) with any dictionary (e.g. uniform): $\mathcal{C}^{(k)} = \{\hat{x}^i_0\}_{i=1,\ldots,L}$
3. Nearest neighbor rule: $W^i_k = \{u_m \in \mathcal{X} : \forall j \neq i\; \|u_m - \hat{x}^i_k\| \leq \|u_m - \hat{x}^j_k\|\}$
4. Centroid rule: $\hat{x}^i_{k+1} = \frac{1}{|W^i_k|} \sum_{u_m \in W^i_k} u_m$
5. Iterate to step 3 until convergence

### Scalar quantization: summary

- $D(R)$, UQ of uniform RV: $D = \sigma_X^2 \cdot 2^{-2R}$
- $D(R)$, UQ of non uniform RV in HR: $D = K_X \sigma_X^2 \cdot 2^{-2R}$
- $D(R)$, OQ in HR (any RV): $\sigma_Q^2 = c_X \sigma_X^2 \cdot 2^{-2R}$
- $c_X$ is the shape factor:
  - $c_X = 1$ for uniform RVs
  - $c_X = \frac{\sqrt{3}}{2}\pi$ for Gaussian RVs
- At any resolution, the LMA produces a non-uniform quantizer which is locally optimal

## Predictive scalar quantization

### Predictive quantization

**Principles**

- Quantization alone is not effective for compression of **non-sparse data**
- Too simple underlying model: SQ neglects dependencies among samples
- Idea: exploit sample correlation by prediction
- Goal: reduction of the signal's variance by increasing sparsity

### Sparse Signals: a preview

- **Definition**: A signal is sparse if most of its elements are zero or close to zero
- If a sample is close to zero, it can be "neglected" (quantized as zero) without introducing large distortion
- The variance of a sparse signal is low
- Natural signals are not sparse in their original form, but could be after some processing
- The main tools for signal sparsification are **prediction** and **linear transform**

[Figura: Due grafici. Sopra: segnale sinusoidale $x(n) = \cos(2\pi n/n)$. Sotto: trasformata DFT $X(\nu) = \mathrm{DFT}[x(n)]$ — segnale sparso con due picchi]

### Coding scheme

**Open loop scheme**

- $x(n)$ is predicted from the past
- If the prediction is good, $v(n) \approx x(n)$

[Figura: Schema a blocchi open loop: $x(n) \to \Sigma$ (sottrae $v(n)$) $\to y(n) \to Q \to \hat{y}(n) \to \Sigma$ (aggiunge $v(n)$) $\to \hat{x}(n)$]

- How to provide $v(n)$?
- What is the gain?

### Prediction gain

Prediction Error = Signal Error:

$$q(n) = y(n) - \hat{y}(n) = x(n) - v(n) - \hat{x}(n) + v(n) = \tilde{q}(n)$$

Thus the goal of predictive quantization (PQ) is to minimize the distortion of $y$.

The coding gain is:

$$\mathrm{SNR}_P = 10\log_{10} \frac{\sigma_X^2}{D} = 10\log_{10} \frac{\sigma_X^2}{\sigma_Y^2} + 10\log_{10} \frac{\sigma_Y^2}{D} = G_P + G_Q$$

*Prediction is effective if and only if the prediction error has a smaller variance than the original signal.*

### Example

$$X(n) \sim \mathcal{N}(0, \sigma^2) \qquad \mathrm{E}[X(n)X(m)] = \sigma^2 \rho^{|n-m|}$$
$$V(n) = X(n-1) \qquad \rho: G_P > 0?$$

$$Y(n) = X(n) - X(n-1) \quad \text{Zero mean Gaussian RV}$$
$$\sigma_Y^2 = \mathrm{E}\!\left[(X(n) - X(n-1))^2\right] = 2\sigma^2 - 2\sigma^2\rho$$
$$G_P = 10\log_{10} \frac{\sigma_X^2}{\sigma_Y^2} = 10\log_{10} \frac{\sigma^2}{2(1-\rho)\sigma^2}$$
$$G_P > 0 \Leftrightarrow \rho > \frac{1}{2}$$

### Predictors

Linear Predictors are simple and moreover optimal for Gaussian RV:

$$v(n) = -\sum_{i=1}^{P} a_i x_{n-i} \qquad \text{Filter with } P \text{ parameters}$$

$$y(n) = x(n) - v(n) = \sum_{i=0}^{P} a_i x_{n-i} \qquad \text{Prediction error}$$

with $a_0 = 1$.

$y$ is the result of filtering $x$ with $A(z) = 1 + a_1 z^{-1} + \ldots + a_P z^{-P}$

Optimal filter: minimization of $\sigma_Y^2$

### Predictor selection

Problem: Find the vector $\underline{a}$ minimizing

$$\sigma_Y^2 = \mathrm{E}\!\left\{Y^2(n)\right\} = \mathrm{E}\!\left\{\left[X(n) + \sum_{i=1}^{P} a_i X(n-i)\right]^2\right\}$$

$$\sigma_Y^2 = \mathrm{E}\!\left\{X^2(n)\right\} + 2\sum_{i=1}^{P} a_i \mathrm{E}\!\left\{X(n)X(n-i)\right\} + \sum_{i=1}^{P}\sum_{j=1}^{P} a_i a_j \mathrm{E}\!\left\{X(n-i)X(n-j)\right\}$$

$$= \sigma_X^2 + 2\underline{r}^T \underline{a} + \underline{a}^T R_X \underline{a}$$

with:

$$\underline{r} = \begin{bmatrix} r_X(1) \\ \vdots \\ r_X(P) \end{bmatrix} \qquad R_X = \begin{bmatrix} r_X(0) & r_X(1) & r_X(2) & \cdots & r_X(P-1) \\ r_X(1) & r_X(0) & r_X(1) & \cdots & r_X(P-2) \\ r_X(2) & r_X(1) & r_X(0) & \cdots & r_X(P-3) \\ \vdots & \vdots & \vdots & & \vdots \\ r_X(P-1) & r_X(P-2) & r_X(P-3) & \cdots & r_X(0) \end{bmatrix}$$

$$r_X(k) = \mathrm{E}\!\left\{X(n)X(n-k)\right\}$$

Minimization of $Y$ variance:

$$\frac{\partial \sigma_Y^2}{\partial \underline{a}} = 2\underline{r} + 2R_X \underline{a} = 0$$

Thus:

$$\underline{a}^{\mathrm{opt}} = -R_X^{-1}\, \underline{r} \qquad \sigma_Y^2 = \sigma_X^2 + \underline{r}^T \underline{a}^{\mathrm{opt}}$$

Autocorrelation $r_X$ can be estimated as:

$$\hat{r}_X(k) = \frac{1}{N} \sum_{n=0}^{N-1-k} X(n)X(n+k)$$

### Predictive quantization: example

For the "peppers" image (grayscale), we compute the prediction error using a second order linear predictor:

$$\tilde{f}_{n,m} = a\, f_{n-1,m} + b\, f_{n,m-1}$$

The predictor of $f_{n,m}$ is a weighted average of the top and the left neighbors.

| $a$ | $b$ | $\sigma_E^2$ |
|-----|-----|-------------|
| 0 | 0 | 2902.7 |
| 1/2 | 1/2 | 78.7 |
| 0.449 | 0.546 | 78.4 |

The first row corresponds to no prediction: thus $\sigma_X^2 = 2902.7$.
The second row shows the distortion of the simplest predictor: the average of the two neighbors. The distortion is reduced by a factor greater than 37.
Using the optimal predictor, computed with the formulas shown in the previous slide, only slightly improves the performance.

### Impact of Filter Order on Prediction Gain

In global DPCM, the predictor $v(n)$ uses a linear combination of $N$ causal neighbors.

- **Order Selection**: Increasing the order from 2 to 4 typically improves the Prediction Gain ($G_P = \sigma_X^2/\sigma_Y^2$), leading to a more "whitened" residual.
- **Screening Effect**: The benefit of including "distant" pixels diminishes rapidly. In typical image statistics, the immediate neighbors capture most of the mutual information. Distant pixels are often redundant as their correlation with the target is already "screened" by the closer neighbors.
- **Complexity vs. Performance**: Higher orders increase computational overhead with negligible PSNR gains for most natural textures.

### Local Adaptation: The Block-wise Approach

Images are **non-stationary** signals; a single global filter is suboptimal for varying textures (e.g., edges vs. smooth areas).

**The Strategy**: Divide the image into $M \times M$ blocks and compute the locally optimal filter for each.

**The Side Information Trade-off**: Total Rate ($R_{\mathrm{total}}$) is now increased by $\frac{N \cdot B}{M^2}$ where $N$ is the filter order and $B$ is the bits per coefficient (e.g., 16).

- **Small Blocks**: Excellent tracking of local statistics, but massive overhead from filter coefficients.
- **Large Blocks**: Minimal overhead, but the predictor fails to adapt to local features.

### Coding/decoding scheme

**Wrong scheme:**

[Figura: Schema a blocchi con encoder (sinistra) e decoder (destra). All'encoder il predittore P usa campioni originali non quantizzati $x(n-1), x(n-2), \ldots, x(n-p)$; al decoder usa campioni ricostruiti $\tilde{x}(n-1), \ldots$]

**WRONG!** The predictor operator is the same at the encoder and decoder but the input is different: $x \neq \tilde{x}$! This causes **drift**.

### Coding scheme

- The encoder computes the prediction error $Y = X - V$
- The predictor $V$ must be computed from data available at the decoder as well
- Thus the encoder must compute the reconstructed value $\tilde{X}$
- This value is sent into a buffer and used to compute the prediction of future values

### Direct vs. Predictive quantization

[Figura: Grafico PSNR (dB) vs $\log_2 L$ per "lena", con due curve: Direct quantization (blu) e Predictive quantization (arancio)]

We show here the PSNR of the quantized image vs. the $\log_2 L$, which is our first rate estimation. The result seems very deceiving: apart from a short range of high rates, predictive quantization does not bring the expected gain: how is this possible?

The main explanation is that a practical PQ scheme must use the quantized data to produce a predictor, which is not what we considered in our theoretical analysis.

[Figura: Grafico PSNR (dB) vs $\log_2 L$ per "peppers"]

For the peppers image things are even worse:
- At low bitrates, the predictor is computed on heavily quantized data
- At high bitrates, the quantizer is obliged to reconstruct the additive noise affecting the image

However, the main point is that **the estimation of the rate with the logarithm is too much pessimistic**.

### PQ prediction error

[Figura: Mappa dell'errore di predizione (colori giallo/verde/blu) e istogramma degli indici di quantizzazione — distribuzione quasi-gaussiana molto concentrata attorno a 0, con $L = 19$ livelli]

Let us look more closely to the quantized prediction error. In this example, $L = 19$, so the estimated rate is $\log_2 19 \approx 4.25$ bits per sample.

However, we observe that most of the quantization indexes ($\approx 84\%$) are zero. We could use a **variable length code** that uses a short codeword for the index 0 and possibly longer codewords for indexes outside $(-3, 3)$, which account for less than 1% of the total.

Encoding the quantization indexes with non-trivial encoding strategy (called **entropy coding**, as we will see later on) changes dramatically the results.

## Quantization: wrap-up

- **UQ**: $D = K_X \sigma_X^2 \cdot 2^{-2R}$ for uniform RV or in high res
- **Optimal SQ**: similar behavior
- Both UQ and optimal SQ alone are **catastrophic** if applied directly on images or sound: the quality drops and the rate is not reduced much
- **Predictive quantization** can improve dramatically performance but:
  1. Never forget to compute the prediction on **quantized data**, otherwise the decoder will drift
  2. The input signal **must be correlated enough**
  3. **We must use the best encoding strategy to achieve good performance**

The best encoding strategy is **entropy coding**, the subject of the next lesson.
