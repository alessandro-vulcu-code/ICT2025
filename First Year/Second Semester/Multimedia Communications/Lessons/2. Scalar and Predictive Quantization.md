## Definitions

### Quantizer Model

**Quantization**: mapping a signal from a continuous (or large discrete) set to a signal taking only a **finite number of values**.

- Used to represent analog/high-precision signals with fewer bits
- Fundamental operation in any lossy compression system
- Introduces **irreversible** information loss (distortion)

A quantizer $Q$ is defined by:
- **Thresholds**: $-\infty = t^0 < t^1 < \cdots < t^{L-1} < t^L = +\infty$
- **Quantization regions**: $\Theta^i = [t^{i-1}, t^i)$ for $i = 1, \ldots, L$
- **Reconstruction levels** (dictionary): $\hat{x}^1, \hat{x}^2, \ldots, \hat{x}^L$

The quantizer maps: $x \in \Theta^i \Rightarrow Q(x) = \hat{x}^i$

A **scalar quantizer (SQ)** operates on one sample at a time: $\tilde{X} = Q(X)$.
![[Pasted image 20260501165859.png|700]]
### Key Quantities

| Quantity | Formula | Units |
| :--- | :--- | :--- |
| **Quantization error** | $e = X - Q(X) = X - \tilde{X}$ | — |
| **Distortion (MSE)** | $D = \sigma_Q^2 = \mathbb{E}[(X - Q(X))^2]$ | — |
| **Rate** | $R = \log_2 L$ | bits/sample |
| **SNR** | $10\log_{10}\frac{\mathbb{E}\{X^2\}}{D} = 10\log_{10}\frac{\sigma_X^2}{\sigma_Q^2}$ | dB |

### Types of Quantizers

- **Uniform quantizer (UQ)**: all quantization regions have equal width $\Delta$
- **Non-uniform quantizer**: variable-width regions adapted to the input PDF

### Noise Regimes

- **Granular noise**: input $x$ inside dynamic range $[-A/2, A/2]$ → error bounded: $|e| \leq \Delta/2$
- **Overload (clipping) noise**: input $x$ outside dynamic range → error arbitrarily large

## Uniform Quantization

### Definition and Formula

**Uniform quantizer (UQ)**: partitions $[-A/2, A/2]$ into $L$ equal intervals of width:

$$\Delta = \frac{A}{L} = A \cdot 2^{-R}$$

Reconstruction levels at interval centers:

$$\hat{x}^i = -\frac{A}{2} + \left(i - \frac{1}{2}\right)\Delta, \quad i = 1, \ldots, L$$

**Midrise formula**:

$$Q(x) = \Delta \cdot \left\lfloor\frac{x}{\Delta} + \frac{1}{2}\right\rfloor \quad \text{(with saturation at } \pm A/2\text{)}$$

### Design Trade-offs

**Step size vs. clipping tradeoff** (fixed $A$):
- Small $\Delta$ (large $L$): fine quantization, low granular noise, but high-peak signals clip more often
- Large $\Delta$ (small $L$): coarse quantization, high granular noise, wider dynamic range

**Dynamic range $A$ selection**:
- Too small $A$ → frequent clipping, high distortion
- Too large $A$ → fine quantization wasted on the large range; increased granular noise per bit budget

## Rate-Distortion Curve

### Probability Refreshers

**Uniform RV**: $X \sim \mathcal{U}(a,b)$:
$$f_X(x) = \frac{1}{b-a} \quad \text{for } a\leq x\leq b, \qquad \text{Var}(X) = \frac{(b-a)^2}{12}$$

**LOTUS** (Law of the Unconscious Statistician): for any $g(X)$:
$$\mathbb{E}[g(X)] = \int_{-\infty}^{+\infty} g(x)\, f_X(x)\, dx$$

### UQ of Uniform RV: Exact R-D Derivation

**Hypothesis**: $X \sim \mathcal{U}(-A/2, A/2)$, UQ with $L$ levels.

> [!Important] UQ Distortion for Uniform RV
> $$\sigma_Q^2 = \mathbb{E}[(X-\tilde{X})^2] = \frac{1}{A}\sum_{i=1}^L \int_{\hat{x}^i-\Delta/2}^{\hat{x}^i+\Delta/2}[u-\hat{x}^i]^2\,du = \frac{1}{A}\cdot L \cdot\frac{\Delta^3}{12} = \frac{\Delta^2}{12}$$
>
> Since $\Delta = A/L = A\cdot 2^{-R}$ and $\sigma_X^2 = A^2/12$:
> $$D = \frac{\Delta^2}{12} = \frac{A^2}{12 L^2} = \sigma_X^2 \cdot 2^{-2R}$$
>
> $$\mathrm{SNR} = 10\log_{10}\frac{\sigma_X^2}{\sigma_X^2 \cdot 2^{-2R}} = 10\log_{10}(2^{2R}) \approx 6R \quad \text{[dB]}$$
>
> **Rule of thumb**: every additional bit ≈ +6 dB SNR.

### HR UQ for Generic RV

**Hypothesis**: $L \to +\infty$ (high resolution — HR), $X$ generic RV.

In HR, within any region $\Theta^i$, $p_X$ is approximately constant → quantization error $\sim \mathcal{U}(-\Delta/2, \Delta/2)$ in each region → by total probability law, overall error $\sim \mathcal{U}(-\Delta/2, \Delta/2)$.

> [!Important] HR UQ for Generic RV
> $$D = \frac{\Delta^2}{12} = \frac{A^2}{12}\cdot 2^{-2R} = K_X\,\sigma_X^2\cdot 2^{-2R}$$
>
> where the **load factor** $\gamma^2 = \frac{A^2/4}{\sigma_X^2}$ and $K_X = \gamma^2/3$.
>
> $$\mathrm{SNR} \approx 6R - 10\log_{10}\frac{\gamma^2}{3}$$
>
> **Intuition**: $K_X$ penalizes the mismatch between dynamic range $A$ and signal variance $\sigma_X^2$.

## Optimal Scalar Quantization

### HR Optimal Quantizer

For a given PDF $p_X(x)$, find thresholds and levels minimizing $D$ for fixed $R$.

Under HR hypothesis ($L\to\infty$, $\max_i\Delta_i\to0$, $p_X$ approximately constant per region):

> [!Important] Optimal Quantizer (HR) — R-D Curve
> $$\sigma_Q^2 = c_X\,\sigma_X^2\cdot 2^{-2R}$$
>
> where $U = X/\sigma_X$ (normalized input) and:
> $$c_X = \frac{1}{12}\left[\int_{\mathbb{R}} p_U^{1/3}(t)\,dt\right]^3$$
>
> **Analytic solution exists only in HR.** For finite $R$, use the Lloyd-Max algorithm.

### Shape Factor

$c_X$ is the **shape factor** — depends only on the PDF *shape*, not on variance.

| Distribution | Shape Factor $c_X$ |
| :--- | :--- |
| Uniform | $1$ |
| Gaussian | $\frac{\sqrt{3}}{2}\pi \approx 2.72$ |

*Note: Gaussian signals require ~2.72× more distortion than uniform at the same rate. This reflects the heavier tails.*

### Lloyd-Max Algorithm

Used when HR hypothesis does not hold (low/very low rate). Finds a **local optimum** via alternating optimization.

> [!Important] Lloyd-Max Algorithm — Two Necessary Conditions
>
> **Nearest Neighbor Rule** (best thresholds given levels):
> $$k = \arg\min_n |x - \hat{x}^n| \Rightarrow Q(x) = \hat{x}^k$$
> $$t^i = \frac{\hat{x}^i + \hat{x}^{i+1}}{2}$$
> *Threshold = midpoint between consecutive levels.*
>
> **Centroid Condition** (best levels given thresholds):
> $$\hat{x}^i = \frac{\int_{t^{i-1}}^{t^i} u\,p_X(u)\,du}{\int_{t^{i-1}}^{t^i} p_X(u)\,du} = \mathbb{E}[X\mid X\in\Theta^i]$$
> *Level = conditional mean of $X$ in its region.*
>
> **Proof (centroid):** Minimize $\sigma_Q^2$ w.r.t. $\hat{x}^i$:
> $\frac{\partial\sigma_Q^2}{\partial\hat{x}^i} = 2\hat{x}^i\int_{\Theta_i}p_X\,du - 2\int_{\Theta_i}u\,p_X\,du = 0 \Rightarrow \hat{x}^i = \mathbb{E}[X\mid X\in\Theta^i]$

**Algorithm**:
1. Initialize dictionary $\mathcal{C}^{(0)}$ (uniform or random)
2. Apply nearest neighbor rule → update thresholds
3. Apply centroid condition → update levels
4. Compute $\sigma^2_{Q,(k)}$; stop if $\frac{\sigma^2_{Q,(k-1)}-\sigma^2_{Q,(k)}}{\sigma^2_{Q,(k-1)}} < \varepsilon$ or $k = K$

**Convergence properties**:
- Distortion never increases across iterations
- Convergence to **global optimum not guaranteed**
- Final result depends on initialization

### Lloyd-Max for Data

When PDF is unknown but data is available (training set $\mathcal{X} = \{u_1,\ldots,u_M\}$):

1. Initialize dictionary $\mathcal{C}^{(0)} = \{\hat{x}^i_0\}$
2. **Nearest neighbor**: $W^i_k = \{u_m\in\mathcal{X}: \forall j\neq i, \|u_m-\hat{x}^i_k\|\leq\|u_m-\hat{x}^j_k\|\}$
3. **Centroid**: $\hat{x}^i_{k+1} = \frac{1}{|W^i_k|}\sum_{u_m\in W^i_k}u_m$
4. Repeat until convergence

*(Note: same structure as k-means clustering)*

## Predictive Scalar Quantization

### Motivation and Sparse Signals

SQ neglects dependencies among samples — fails to exploit signal correlation.

> [!Important] Sparse Signal
> A signal is **sparse** if most elements are zero or near zero.
> - Sparse → low variance → efficient quantization (set near-zero values to 0 without large distortion)
> - Natural signals are NOT sparse in their original domain, but may become sparse after **prediction** or **linear transform**

![[Pasted image 20260501171327.png]]
### Open-Loop Coding Scheme
![[Pasted image 20260501171341.png]]
**Prediction error signal**: $y(n) = x(n) - v(n)$, where $v(n)$ is the predictor output.

If prediction is good → $v(n) \approx x(n)$ → $y(n)$ has small variance → more efficient quantization.

### Prediction Gain

Key identity: **prediction error = quantization error on original signal**:
$$q(n) = y(n) - \hat{y}(n) = [x(n)-v(n)] - [\hat{x}(n)-v(n)] = x(n) - \hat{x}(n)$$

Total SNR decomposition:
$$\mathrm{SNR}_P = 10\log_{10}\frac{\sigma_X^2}{D} = \underbrace{10\log_{10}\frac{\sigma_X^2}{\sigma_Y^2}}_{G_P \text{ (prediction gain)}} + \underbrace{10\log_{10}\frac{\sigma_Y^2}{D}}_{G_Q \text{ (quantization gain)}}$$

> [!Important] Condition for Positive Prediction Gain
> Prediction is effective **if and only if** $\sigma_Y^2 < \sigma_X^2$, i.e., $G_P > 0$.

> [!Example] Prediction Gain for AR(1) Signal
> **Signal:** $X(n)\sim\mathcal{N}(0,\sigma^2)$ with $\mathbb{E}[X(n)X(m)] = \sigma^2\rho^{|n-m|}$
>
> **Predictor:** $V(n) = X(n-1)$ (previous sample)
>
> **Prediction error variance:**
> $$\sigma_Y^2 = \mathbb{E}[(X(n)-X(n-1))^2] = 2\sigma^2 - 2\sigma^2\rho = 2\sigma^2(1-\rho)$$
>
> **Prediction gain:**
> $$G_P = 10\log_{10}\frac{\sigma^2}{2(1-\rho)\sigma^2} = 10\log_{10}\frac{1}{2(1-\rho)}$$
>
> **Condition:** $G_P > 0 \Leftrightarrow \rho > \frac{1}{2}$
>
> For $\rho = 0.9$: $G_P = 10\log_{10}\frac{1}{0.2}\approx 7$ dB

### Linear Predictors

Linear predictors are simple and **optimal for Gaussian RVs**:

$$v(n) = -\sum_{i=1}^{P} a_i\, x_{n-i} \qquad \text{(order-$P$ filter)}$$

$$y(n) = x(n) - v(n) = \sum_{i=0}^{P} a_i\, x_{n-i} \qquad (a_0 = 1)$$

$y$ = output of FIR filter $A(z) = 1 + a_1 z^{-1} + \cdots + a_P z^{-P}$ applied to $x$.

**Goal**: minimize $\sigma_Y^2 = \mathbb{E}[Y^2(n)]$ by optimizing $\underline{a} = [a_1,\ldots,a_P]^T$.

### Optimal Predictor Selection

Expanding $\sigma_Y^2$:

$$\sigma_Y^2 = \sigma_X^2 + 2\underline{r}^T\underline{a} + \underline{a}^T R_X\,\underline{a}$$

where:
$$\underline{r} = [r_X(1),\ldots,r_X(P)]^T, \qquad (R_X)_{ij} = r_X(|i-j|), \qquad r_X(k) = \mathbb{E}[X(n)X(n-k)]$$

> [!Important] Optimal Predictor (Wiener-Hopf)
> $$\frac{\partial\sigma_Y^2}{\partial\underline{a}} = 2\underline{r} + 2R_X\,\underline{a} = 0 \quad \Rightarrow \quad \underline{a}^{\mathrm{opt}} = -R_X^{-1}\,\underline{r}$$
>
> $$\sigma_{Y,\mathrm{opt}}^2 = \sigma_X^2 + \underline{r}^T\,\underline{a}^{\mathrm{opt}}$$
>
> $R_X$ is the **autocorrelation matrix** (Toeplitz); $\underline{r}$ is the cross-correlation vector.

Autocorrelation estimated from data:
$$\hat{r}_X(k) = \frac{1}{N}\sum_{n=0}^{N-1-k} X(n)X(n+k)$$

### Predictive Quantization Example

2D predictor for "peppers" grayscale image:

$$\tilde{f}_{n,m} = a\,f_{n-1,m} + b\,f_{n,m-1}$$

| $a$ | $b$ | $\sigma_E^2$ | Notes |
| :--- | :--- | :--- | :--- |
| 0 | 0 | 2902.7 | No prediction ($\sigma_X^2$) |
| 1/2 | 1/2 | 78.7 | Simple average of neighbors |
| 0.449 | 0.546 | 78.4 | Optimal predictor |

**Key result**: simple predictor reduces variance by factor >37×. Optimal predictor only marginally better than simple average → near neighbors capture most correlation.

### Filter Order and Block Size

#### Effect of Filter Order
![[Pasted image 20260501173123.png]]
![[Pasted image 20260501173135.png]]

- Higher order (2→4): improves $G_P$ (more whitened residual)
- **Screening effect**: distant pixels already "explained" by immediate neighbors → rapidly diminishing returns
- **Complexity/performance**: higher order = more computation, negligible PSNR gain for natural textures

#### Effect of Block Size (Local Adaptation)

Images are **non-stationary** → single global filter is suboptimal.

**Block-wise strategy**: compute locally optimal filter for each $M\times M$ block.

**Side information overhead**: total rate increases by $\frac{N\cdot B}{M^2}$ (where $N$ = filter order, $B$ = bits per coefficient ≈ 16).

| Block size | Adaptation | Overhead |
| :--- | :--- | :--- |
| Small | Excellent local tracking | Large — many filter sets |
| Large | Minimal overhead | Poor adaptation to local features |

### Drift Problem and Correct Scheme

#### Wrong Scheme (Encoder/Decoder Mismatch)
![[Pasted image 20260501173246.png]]
**Problem**: encoder predictor uses original (unquantized) $x(n)$; decoder uses reconstructed $\tilde{x}(n)$. Since $x\neq\tilde{x}$, the predictions diverge → **drift** accumulates over time.

> [!Example] Drift with Wrong Scheme (3-bit quantizer, levels: -9,-6,-3,0,3,6,9)
>
> | Step | Original | Enc. Pred. | Enc. Error | Quant. Error | Dec. Pred. | Recon. |
> | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
> | 1 | 10 | — | — | 9 | — | 9 |
> | 2 | 11 | **10** | 1 | 0 | **9** | 9 |
> | 3 | 12 | **11** | 1 | 0 | **9** | 9 |
> | 4 | 13 | **12** | 1 | 0 | **9** | 9 |
> | 5 | 14 | **13** | 1 | 0 | **9** | 9 |
> | 6 | 18 | **14** | 4 | 3 | **9** | 12 |
>
> Encoder predicts from original; decoder stuck at 9. Drift grows.

#### Correct Scheme
![[Pasted image 20260501173300.png]]
**Solution**: encoder also uses the **quantized/reconstructed** samples $\tilde{x}(n)$ for prediction — same data as the decoder. Both sides stay synchronized.

> [!Example] No Drift with Correct Scheme (same quantizer)
>
> | Step | Original | Enc. Pred. | Enc. Error | Quant. Error | Dec. Pred. | Recon. |
> | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
> | 1 | 10 | — | — | 9 | — | 9 |
> | 2 | 11 | **9** | 2 | 3 | **9** | 12 |
> | 3 | 12 | **12** | 0 | 0 | **12** | 12 |
> | 4 | 13 | **12** | 1 | 0 | **12** | 12 |
> | 5 | 14 | **12** | 2 | 3 | **12** | 15 |
> | 6 | 18 | **15** | 3 | 3 | **15** | 18 |
> | 7 | 21 | **18** | 3 | 3 | **18** | 21 |
> | 8 | 18 | **21** | −3 | −3 | **21** | 18 |
>
> Encoder and decoder perfectly synchronized — no drift.

**Implementation**: encoder maintains a buffer of quantized past samples $\tilde{x}(n)$; predictor reads from this buffer.

### Impact of Entropy Coding

#### Direct Comparison (without entropy coding)
![[Pasted image 20260501173349.png]]
Without entropy coding, rate estimated as $R = \log_2 L$ (bits/sample). PQ appears disappointing:
- At low bitrates: predictor uses heavily quantized data → unreliable
- At high bitrates: quantizer forced to encode added quantization noise

**Root cause**: rate estimate $\log_2 L$ is **too pessimistic** for PQ.

**Why**: most quantization indexes are zero. Example: $L=19$ levels → $\approx 84\%$ of indexes are 0; less than 1% outside $(-3,3)$.
![[Pasted image 20260501173405.png]]
→ **Variable-length code** (entropy coding): short codeword for index 0, longer for rare non-zero indexes.

#### With Entropy Coding
![[Pasted image 20260501173437.png]]

**Result**: PQ + entropy coding achieves:
- $\Delta\mathrm{PSNR} \approx +20\,\mathrm{dB}$ at 1 bpp vs. direct UQ
- Or equivalently: **−86% rate reduction** at 30 dB target quality

| :--- | :--- | :--- |
| UQ, uniform RV | $D = \sigma_X^2\cdot 2^{-2R}$ | $c_X=K_X=1$ |
| HR UQ, generic RV | $D = K_X\sigma_X^2\cdot 2^{-2R}$ | $K_X = \gamma^2/3$ |
| Optimal SQ (HR) | $D = c_X\sigma_X^2\cdot 2^{-2R}$ | $c_X=1$ (uniform), $c_X\approx2.72$ (Gaussian) |
| SNR rule of thumb | $\mathrm{SNR}\approx 6R$ dB | +6 dB per extra bit |

### Key Takeaways

1. **UQ and optimal SQ alone**: catastrophic for natural images/audio — quality drops, rate barely reduced
2. **Predictive quantization** dramatically improves performance **only when**:
   - Prediction computed on **quantized data** (otherwise decoder drifts)
   - Signal is **sufficiently correlated** ($\rho > 1/2$ for first-order prediction)
   - Followed by **entropy coding** (to exploit the sparsity of prediction errors)
3. **Rate estimate $\log_2 L$ is too pessimistic** for PQ — entropy coding reveals the true gain
4. **Entropy coding** is the essential final step: subject of the next lesson
