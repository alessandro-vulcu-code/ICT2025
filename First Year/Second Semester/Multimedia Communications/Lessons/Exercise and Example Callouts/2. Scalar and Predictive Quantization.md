# 2. Scalar and Predictive Quantization - Exercise and Example Callouts

> [!Example] Prediction Gain for AR(1) Signal
> **Signal:** $X(n)\sim\mathcal{N}(0,\sigma^2)$ with $\mathbb{E}[X(n)X(m)] = \sigma^2\rho^{|n-m|}$
>
> **Predictor:** $V(n) = X(n-1)$ (previous sample)
>
> **Prediction error variance:**
> $$\sigma_Y^2 = \mathbb{E}[(X(n)-X(n-1))^2] = 2\sigma^2 - 2\sigma^2\rho = 2\sigma^2(1-\rho)$$
>
> **Prediction gain:**
> $$G_P = 10\log_{10}\frac{\sigma^2}{2(1-\rho)\sigma^2} = 10\log_{10}\frac{1}{2(1-\rho)}$$
>
> **Condition:** $G_P > 0 \Leftrightarrow \rho > \frac{1}{2}$
>
> For $\rho = 0.9$: $G_P = 10\log_{10}\frac{1}{0.2}\approx 7$ dB
