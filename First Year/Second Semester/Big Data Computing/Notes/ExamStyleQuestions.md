6. [3 points] Describe the one-round Word Count MapReduce algorithm. Analyze $R$, $M_L$, and $M_A$ in terms of the number of documents $k$, the maximum document length $N_{\max}$, and the total number of words $N$.

7. [4 points] Consider the Class Count problem where all objects may have the same class. Explain why the one-round naive algorithm can require $M_L=O(N)$, then describe a two-round deterministic partitioning algorithm that achieves sublinear local space.

8. [4 points] A MapReduce algorithm receives $N$ web documents, each represented by a pair $(url,D)$ occupying $O(1)$ space. Describe a map phase that splits the input into $\sqrt{N}$ small partitions and state the theoretical guarantees of the partitioning.
