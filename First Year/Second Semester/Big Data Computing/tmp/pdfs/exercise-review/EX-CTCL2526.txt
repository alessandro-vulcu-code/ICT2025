  1. d(x, y) ≥ 0;

  2. d(x, y) = 0 if and only if x = y;

  3. d(x, y) = d(y, x); (symmetry)

  4. d(x, z) ≤ d(x, y) + d(y, z); (triangle inequality)

Exercise 2 Consider a pointset P of N points represented as set of key-value pairs (IDx , x),
where IDx is a distinct integer in [0, N ), and x is a point. Let also S be a set of k centers.
Considering S as a global variable, show the assignment of each point to the closest center
can be performed in MapReduce in 1 round using ML = O (k).
Solution. We prescribe that for each input point (IDx , x) the output pair (IDx , (x, c(x)))
is returned, where c(x) ∈ S is the center closest to x (with ties broken arbitrarily). We
first consider the following straightforward algorithm.
Round 1
    • Map phase: map each pair (IDx , x) into (IDx , (x, c(x) = argminc∈S d(x, c))).
    • Reduce phase: empty.
We have that ML = Θ (k), since each application of the map function requires space Θ (k)
for storing a copy of S.

IMPORTANT OBSERVATION. If we ignore the space occupied by the copies of S, the
aggregate space MA is clearly linear in N . In practice, one copy of S is stored at each
worker executing the map phase (for example, in Spark this is the case if S is defined
as a broadcast variable), and if the number of workers is O (N/k), which is a reasonable
assumption in most practical scenarios, the aggregate space remains linear in N .      2
Exercise 3 Show that the Farthest-First Traversal algorithm can be implemented to run
in O (N · k) time.
Solution. With each point p we maintain a value called curr-distp which, immeditaley
after center ci is selected, contains the distance between p and the closest center among
c1 , c2 , . . . , ci−1 . Initially, after the arbitrary selection of c1 , curr-distp is set equal to null.
It is easy to see that, for every i ≥ 1, if the property holds after ci is selected, one scan of
the pointset P (O (N ) time) is sufficient to update the value curr-distp with the distance
between p and the closest center among c1 , c2 , . . . , ci , and to select the next center ci+1
as the point p with minimum curr-distp . This immediately implies that Farthest-First
Traversal can be implemented in O (N · k) time.                                                        2
