Exercise 1 With reference to the Boyer-Moore algorithm which finds the majority in a
stream Σ of n elements x1 , x2 , . . . , xn , if one exists, show that the following invariant is
maintained by the algorithm. For every t ≥ 0, after processing xt (if t = 0 this is the start
of the algorithm, before any element is processed) :

   • There are count occurrences of cand in x1 , x2 , . . . , xt .

   • Besides the count occurences of cand, the remaining t−count elements can be grouped
     into (t − count)/2 pairs (e1 , e2 ) with e1 6= e2 .

Solution. For t = 0, the invariant trivially holds since count = 0. Suppose that it holds
after processing x1 , x2 , . . . , xt−1 , for some t − 1 ≥ 0, and let count = c and cand = e at
that time. To show that it holds after processing xt , we distinguish among three cases:

   • CASE 1: c = 0. In this case, after processing xt we have count = 1 and cand = xt .
     Hence, we have 1 occurence of cand in x1 , x2 , . . . , xt , and, from the invariant assumed
     to be true after processing xt−1 , we see that the elements x1 , x2 , . . . , xt−1 can be
     grouped into (t − 1 − c)/2 = (t − 1)/2 pairs (e1 , e2 ) with e1 6= e2 .

   • CASE 2: c > 0 and xt = e. In this case, after processing xt we have count = c + 1
     and cand = e = xt . Hence, considering also xt we have c + 1 occurences of cand in
     x1 , x2 , . . . , xt , and, from the invariant assumed to be true after processing xt−1 , we
     see that the remaining elements can be grouped into (t − 1 − c)/2 = (t − (c + 1))/2
     pairs (e1 , e2 ) with e1 6= e2 .

   • CASE 3: c > 0 and xt 6= e. In this case, after processing xt we have count = c−1 and
     cand = e. From the invariant assumed to be true after processing xt−1 , we obtain
     that there are c − 1 occurences of cand in x1 , x2 , . . . , xt , and that the remaining
     elements can be grouped into 1 + (t − 1 − c)/2 = (t − (c − 1))/2 pairs (e1 , e2 ) with
     e1 6= e2 , where the additional pair (cand, xt ) has been added to them.

Exercise 4 Suppose that S1 and S2 are two m-samples extracted from two streams Σ1
and Σ2 of size n each. Given S1 and S2 , show how to construct an m-sample of the
concatenation of the two steams Σ1 · Σ2 (assume that all elements of the two streams are
distinct).

Solution. An m-sample of Σ1 · Σ2 is a subset S of exactly m elements from Σ1 · Σ2 such
that every x ∈ Σ1 · Σ2 has probability m/(2n) to be in S. Given S1 and S2 , the desired m-
sample can be obtained by computing an m-sample S of S1 ∪ S2 . Indeed, for each element
x ∈ Σ1 , we have:

         Pr[x ∈ S] = Pr[x ∈ S1 ] · Pr[x ∈ S|x ∈ S1 ] = (m/n) · (m/(2m)) = m/2n.

A similar argument holds for each x ∈ Σ2 . Therefore S is an m-sample of Σ1 · Σ2 .          2

Exercise 6 For a stream Σ of n items x1 , x2 , . . . , xn , consider the following algorithm:


   • Run in parallel the Boyer-Moore majority algorithm and the Sticky Sampling algo-
     rithm with ϕ = 1/2.

   • Let cand be the candidate identified by the Boyer-Moore algorithm, and S the set of
     items returned by the Sticky Sampling algorithm.

                     If cand ∈ S then return cand otherwise return null.

What can we say about the output of the algorithm? Distinguish among the case where Σ
contains a majority element and the case where Σ does not contain a majority element.

Solution. Let cand be the item returned by the Boyer-Moore algorithm, and S the set
returned by the Sticky Sampling algorithm.

   • If a majority item A exists in the stream, then we know that cand = A, but the
     proposed algorithm will return it in output only if it is in S, which happens with
     probability at least 1 − δ, where δ is the probability parameter used in Sticky Sam-
     pling. Thus, the majority, if one exists, is returned with probability at least 1 − δ.

   • If a majority element does not exist in Σ, then the algorithm returns null or an element
     in S. However, Sticky Sampling guarantees that any element in S has frequency at
     least ϕ − , that is, (1/2) − , since we set ϕ = 1/2. Then no element with frequency
     lower than (1/2) −  is ever returned.

As an aside, we observe that the algorithm needs only in 1 pass, and the working memory
size and the processing time per element are dominated by those of Sticky Sampling:
namely, the working memory size is O (log(1/(ϕδ))/) = O (log(2/δ)/), and the processing
time per element is O (1) in expectation (using a Hash Table to implement the map). 2

Exercise 11 Consider a Bloom filter built to assess membership for a set S of m elements.
The Bloom filter consists of an n-bit array A and k hash functions h0 , h1 , . . . , hk−1 , mutually
independent and with values uniformly distributed in [0, n − 1]. Assume that n is even,
and that each hash function hi is such that, for every e ∈ S, hi (e) mod n/2 is uniformly
distributed in [0, n/2 − 1].

   1. Show how to transform, in O (n) time, the given Bloom filter into a new Bloom filter
      based on an n/2-bit array B, and describe how to assess membership with the new
      Bloom filter.

   2. Compute the probability that a given cell B[i] of the new array is 0.

Solution.

   1. We define the new array B as follows:

                                      B[i] = A[i] OR A[i + n/2],

      for every 0 ≤ i < n/2. It is immediate to see that the array B is exactly the same
      as the one that would be constructed using the k hash functions h0j , for 1 ≤ j ≤ k,
      where for each e ∈ S, h0j (e) = hj (e) mod n/2. An element x is claimed to be in S
      if h0j (x) = 1 for each 1 ≤ j ≤ k. Note that the construction of B from A can be
      accomplished in O (n) time without using the set S.

   2. Since we assumed that for every e ∈ S and 0 ≤ j < k, hj (e) mod n/2 is uniformly
      distributed in [0, n/2 − 1], the hash functions h0j ’s satisfy the hypotheses of indepen-
      dence and uniform distribution made in the analysis of the Bloom filter presented in
      class. By repeating that analysis, we can conclude that, for sufficiently large n, the
      probability that any given cell B[i] is 0, is very close to e−km/(n/2) = e−2km/n .
