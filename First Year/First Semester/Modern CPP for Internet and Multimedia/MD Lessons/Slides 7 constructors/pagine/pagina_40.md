Default operations

• It is possible to be explicit with respect to what is generated by default using the `=default` keyword

In general:

• it can be good to rely on the compiler than to write a custom implementation (less error-prone)

but

• watch out for shallow copies

• it may be good to use a member initializer list if not sure of the default initialization behavior of a member

• the default initialization of built-in type members for local and free store objects leaves them uninitialized!
