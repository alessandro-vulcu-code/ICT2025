Pointer

• Given type T, T* is the type “pointer to T”

It holds the address of an object of type T

```c
char c = 'a';
char* p = &c;

labels for memory addresses
p: &c
c: 'a'

char c2 = *p; // c2 is 'a'
dereferencing or indirection returns the value at the address in the pointer
```
