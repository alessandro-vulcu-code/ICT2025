Arrays

• Given type T, T[size] is an array of elements of type T

• Sequence of objects in memory – low-level facility

• Access with
  • Subscript operator [ ]
  • Index from 0 to size – 1
  • NO runtime range checks!
  • With a pointer

• Allocation options:
  • Static
  • Stack
  • Free storage (or heap)
