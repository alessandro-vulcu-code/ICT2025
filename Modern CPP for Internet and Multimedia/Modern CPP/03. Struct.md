## 1. Starting with a Familiar Tool: The Array

Before diving into `structs`, let's start with a tool you might already know: the **array**. An array is an aggregate of elements, but with one important rule: all elements must be of the **same type**. For example, you can have an array of integers or an array of characters, but you can't mix them.

This leads to a question: "But what if we want to group a person's name (text), street number (an integer), and town (text) together in one variable?" An array can't handle this because the data types are different.

This is exactly where the `struct` comes in. A `struct` is the C++ solution to this problem, designed as an aggregate of elements that can have **different types**. It allows you to package various pieces of related information into a single, logical unit. Now, let's see how to build the blueprint for one.

## 2. Defining Your First `struct`: The Blueprint

Defining a `struct` is like creating a blueprint for a brand-new data type that you can use throughout your program. You specify what pieces of data it will hold, and then you can create variables of that new type.

Here is the blueprint for a `struct` designed to hold address information:

```cpp
struct Address {
    const char* name;    // A pointer to a constant C-style string
    int number;          // A standard integer
    const char* street;  // A pointer to a constant C-style string
    const char* town;    // A pointer to a constant C-style string
    char state[2];       // A fixed-size array of 2 characters
    const char* zip;     // A pointer to a constant C-style string
};
```

Once the blueprint (`struct Address`) is defined, you can create an actual variable from it. This process is called **instantiation**. We can create and initialize an `Address` variable named `jd` like this:

```cpp
Address jd = {
    "Jim Dandy",
    61,
    "South St",
    "New Providence",
    {'N','J'},
    "07974"
};
```

The values inside the curly braces `{}` correspond directly to the members declared inside the `struct`, in the same order.

**Key Rule:** It's important to know that two `struct` types are considered different by the compiler, even if they have the exact same members. The name you give your `struct` creates a unique type.

Now that we've defined a `struct` and created an instance of it, let's learn how to access and use the data stored inside.

## 3. Accessing and Using `struct` Members

The individual variables declared inside a `struct` (like `name`, `number`, and `street` in our `Address` example) are called **members**. C++ provides a few simple ways to access these members, depending on how you are handling the `struct` object.

The following table breaks down the three primary methods for member access:

|                          |                                                                                |                                                                                                           |
| ------------------------ | ------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------- |
| Method                   | Syntax Example                                                                 | When to Use It                                                                                            |
| **Direct Access**        | `jd.name = "Jim Dandy";`                                                       | Use the **dot (**`.`**) operator** on a direct `struct` object.                                           |
| **Access via Reference** | `void f(Address &addr) { addr.name = ...; }`                                   | Use the **dot (**`.`**) operator** inside a function when you have a reference to an object.              |
| **Access via Pointer**   | `void f(Address *addr) { addr->name = ...; }` <br> _(Alt:_ `_(*addr).name_`_)_ | Use the **arrow (**`->`**) operator** when you have a pointer to an object. This is the preferred syntax. |

Understanding these access methods is key to manipulating the data stored within your `structs`. Next, let's take a peek at how this data is organized in your computer's memory.

## 4. A Look Under the Hood: `structs` and Memory

A fundamental rule of `struct` memory layout is simple and predictable: **members are stored in memory in the order they are declared.**

However, there's a subtle but important detail to be aware of: **memory alignment (or padding)**. To make data processing faster, the computer's architecture sometimes requires certain data types (like an `int`) to start at specific memory addresses. To ensure this, the compiler may insert small, empty gaps between members.

Consider this example `struct`:

```cpp
struct Example {
    char first_member;  // Usually 1 byte
    int  second_member; // Usually 4 bytes
    char third_member;  // Usually 1 byte
};
```

If you simply add up the sizes of the members, you get 6 bytes (1 + 4 + 1). However, due to padding, the actual size of the `struct` in memory might be larger. For instance, the compiler might add 3 bytes of padding after `first_member` to ensure `second_member` starts on a 4-byte boundary.

To see the actual memory footprint on your specific machine, you can use the `sizeof()` operator. For example, `sizeof(Example)` will give you the true size in bytes, including any padding.

So far, our `struct` just holds data. Let's see how we can give it custom functionality to make it even smarter.

## 5. Making `structs` Smarter: An Introduction to Constructors

In C++, a `struct` is essentially a "simple version of a class." This means it can have special member functions, including **constructors**.

The primary benefit of a constructor is to **enforce invariants**—conditions that must always be true for an object to be in a valid state. A constructor runs automatically when an object is created, ensuring it is properly initialized from the very beginning.

Let's look at a `struct` that uses a constructor to guarantee it's created correctly:

```cpp
#include <vector> // Required for std::vector

struct Points {
    std::vector<int> elem;

    // This is the constructor
    Points(int n1, int n2) {
        elem.push_back(n1);
        elem.push_back(n2);
    }
};
```

In this `Points` struct, the constructor takes two integers as arguments and immediately adds them to its internal vector, `elem`. This guarantees that any `Points` object we create will always contain at least two points right from the start.

**The Most Important Rule:** If you explicitly declare _any_ constructor for your `struct`, C++ will **no longer provide a default (empty) constructor** for you automatically. This is because once you define _any_ constructor, you are telling the compiler, "I have a specific way this object must be created." The compiler will no longer assume that creating an empty object with no arguments is a valid operation.

## 6. Summary: Your `struct` Essentials

You've now learned that `structs` are a powerful and fundamental tool in C++ for organizing complex data in a logical and readable way. They allow you to create your own custom data types that perfectly fit the problem you are trying to solve.

Here are the most critical concepts to remember:

- `struct` **vs. Array:** Use a `struct` for grouping related data of _different_ types. Use an array for a collection of elements of the _same_ type.
- **Accessing Members:** Use the dot (`.`) operator when working with `struct` objects and references. Use the arrow (`->`) operator when working with pointers to `structs`.
- **Memory Layout:** Members are arranged in memory in the order they are declared, but be aware that the compiler may add padding for alignment purposes.
- **Constructors:** You can add constructors to your `structs` to ensure that objects are always created in a valid and predictable state.
