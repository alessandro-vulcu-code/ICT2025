Constructor

• Same name of the class (it cannot be reused for anything else in the class)
• No return type
• It established invariants - set of rules that hold throughout the object life cycle
• When invariants are specified up front (in the constructor), they can ease a number of operations:
  • Clarify the behavior of the class
  • Simplify the definition of member functions (e.g., they may not need to consider some edge cases)
  • Clarify how the class manages the resources it owns
  • Simplify the documentation
