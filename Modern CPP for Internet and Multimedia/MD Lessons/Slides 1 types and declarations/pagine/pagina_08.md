Sizes

• `<cstdint>` header has the definition of types with precise size (e.g., `int16_t`)
  • `int` and `uint32_t` are not portable, `uint_fast32_t` is

• `<cstddef>` header has `size_t` -> type that can hold the size in byte of any object
