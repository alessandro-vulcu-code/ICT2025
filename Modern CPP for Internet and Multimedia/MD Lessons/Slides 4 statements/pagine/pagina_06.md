if conditions

• You can use a boolean value or an expression
• If different from a boolean, there is an implicit conversion

```c
int x = 1
if (x) // equivalent to if(x≠0)
{
    // do something
}

int *p = &x
if(p) // eq. to if(p≠nullptr)
{
    // do something
}
```
