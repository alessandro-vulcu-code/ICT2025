# for statements

• auto may be handy
  ```c
  std::vector<T> c;
  for (auto p = c.begin(); p ≠ c.end(); ++p)
  {
    // do something
  }
  ```

• there is flexibility in the statement of the for loop
  ```c
  int i = 0;
  for (; i < 10;)
  {
    i++;
  }
  ```

• in these cases, however, a while statement is clearer
