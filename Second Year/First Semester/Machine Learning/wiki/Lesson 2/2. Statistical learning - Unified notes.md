## 1. Reinforcement learning: the introductory connection

In reinforcement learning, an agent learns through interaction with an environment. At time $t$, it observes information about the environment, represented in the introductory model by a state $x_t$, and selects an action $u_t$ using a **policy**:

$$
u_t = \pi(x_t).
$$

The action affects the environment and produces feedback, represented by a reward such as

$$
r_t = g(u_t,x_t).
$$

The agent uses experience to improve its policy and maximize cumulative reward. For example, when driving, actions include steering and braking; rewards can reflect reaching a destination quickly and safely. Actions affect future situations, so the objective concerns rewards over time, not only the immediate reward.

The connection with control theory is that maximizing reward can be written as minimizing cost by choosing $c_t=-r_t$. The controller is data-driven when its improvement uses observations gathered through interaction. In general, measurements need not reveal the complete state; the lecture uses a simplified state description.

The rest of this lesson introduces the statistical framework for supervised learning.

## 3. Inputs, outputs, and training samples

> [!info] Definition — Input and output spaces
> The input space $\mathcal{X}$ contains the possible inputs $x$. The output or label space $\mathcal{Y}$ contains the possible outputs $y$.

In **classification**, outputs are discrete categories. In **regression**, outputs are numerical quantities, often with $\mathcal{Y}=\mathbb{R}$.

For handwritten digit recognition, an input is an image and its output is a digit:

$$
\mathcal{Y}=\{0,1,\ldots,9\}.
$$

A $d\times d$ grayscale image can be vectorized into $d^2$ pixel values, so $\mathcal{X}\subseteq\mathbb{R}^{d^2}$. In particular, an $8\times8$ image has 64 entries. The transcript's statement that a $6\times6$ image gives 64 entries is incorrect: it gives 36.

The main theoretical example later in this lesson uses binary classification, with $\mathcal{Y}=\{0,1\}$.

> [!info] Definition — Training sample
> A training sample consists of $m$ labeled examples:
> $$
> S=(z_1,\ldots,z_m),\qquad z_i=(x_i,y_i)\in\mathcal{X}\times\mathcal{Y}.
> $$
> It is also called a training set or dataset.

The lecture writes $S=\{(x_i,y_i)\}_{i=1}^m$. The indexed-sample interpretation retains repeated observations. Each label is paired with its corresponding input. Use $m$ consistently for the number of examples.

## 4. How data are generated

### 4.1 Deterministic labels

In the simplified model,

$$
x_i\overset{\mathrm{i.i.d.}}{\sim}\mathcal{D}_{\mathcal{X}},
\qquad y_i=f(x_i),
$$

where $\mathcal{D}_{\mathcal{X}}$ is an unknown input distribution and $f:\mathcal{X}\to\mathcal{Y}$ is an unknown labeling function.

The input is random, but its label is completely determined once the input is fixed. The learner sees examples, not the full distribution or the labeling rule.

**Independent and identically distributed (i.i.d.)** means that examples are sampled independently and according to the same distribution. This assumption concerns different examples: it does not say that $x_i$ and $y_i$ within one example are independent.

### 4.2 Random labels given an input

A more general model allows uncertainty in the output even after the input is known:

$$
x\sim\mathcal{D}_{\mathcal{X}},
\qquad y\mid x\sim\mathcal{D}_{\mathcal{Y}\mid\mathcal{X}}(\cdot\mid x).
$$

Equivalently, the pair $z=(x,y)$ follows a joint distribution $\mathcal{D}$. For probability mass functions or densities, the factorization is

$$
p(x,y)=p(y\mid x)p(x).
$$

The conditional distribution depends on $x$; this is not a claim that the joint distribution is a product of independent marginals. Noise, missing information in the input, or ambiguous labels can motivate this model.

### 4.3 The deterministic model is a special case

If $y=f(x)$, the conditional distribution places all its mass on $f(x)$:

$$
\mathbb{P}(Y=f(x)\mid X=x)=1.
$$

For discrete labels,

$$
\mathbb{P}(Y=y\mid X=x)=
\begin{cases}
1,&y=f(x),\\
0,&y\ne f(x).
\end{cases}
$$

For real-valued labels, this is a **Dirac probability measure** concentrated at $f(x)$, written $\delta_{f(x)}$. It need not have an ordinary probability density.

Thus, in either model we can write

$$
z_1,\ldots,z_m\overset{\mathrm{i.i.d.}}{\sim}\mathcal{D},
\qquad S\sim\mathcal{D}^m.
$$

Future examples used to define performance also follow $\mathcal{D}$ and are independent of the training sample.

> [!warning] Deterministic labels do not imply realizability
> The existence of a labeling function $f$ does not automatically mean that $f$ belongs to the chosen hypothesis class $\mathcal{H}$. The additional assumption that the class contains a zero-risk predictor is called realizability.

## 5. Hypotheses and learning algorithms

> [!info] Definition — Hypothesis class
> A hypothesis is a prediction function $h:\mathcal{X}\to\mathcal{Y}$. A hypothesis class $\mathcal{H}$ is the collection of candidate functions the learner may select.

The learning algorithm maps a sample to a hypothesis:

$$
A:(\mathcal{X}\times\mathcal{Y})^m\to\mathcal{H},
\qquad S\mapsto A(S)=\hat h_S.
$$

Keep the two operations distinct: **training** applies $A$ to $S$ to obtain a function; **prediction** applies that function to a new input $x$ to obtain $\hat h_S(x)$.

The class $\mathcal{H}$ determines the available models. The algorithm determines which model is selected using the observed data. The hat indicates an estimate, and the subscript $S$ records its dependence on the sample.

## 6. Loss functions: evaluating one prediction

> [!info] Definition — Loss
> A loss function assigns a nonnegative penalty to a hypothesis evaluated on one labeled example:
> $$
> \ell:\mathcal{H}\times(\mathcal{X}\times\mathcal{Y})\to[0,\infty),
> \qquad (h,z)\mapsto\ell(h,z).
> $$
> Smaller loss means better performance according to the chosen criterion.

### 6.1 Classification: zero-one loss

$$
\ell(h,(x,y))=\mathbf{1}_{\{h(x)\ne y\}}
=\begin{cases}
0,&h(x)=y,\\
1,&h(x)\ne y.
\end{cases}
$$

This applies to both binary and multiclass classification. Every incorrect prediction receives the same penalty. If different mistakes have different consequences, a different loss can assign them different costs. Choosing the loss is part of specifying the learning objective.

### 6.2 Regression: squared and absolute loss

For $y\in\mathbb{R}$, define the prediction error $e=y-h(x)$. Two common losses are

$$
\ell_{\mathrm{sq}}(h,(x,y))=e^2,
\qquad
\ell_{\mathrm{abs}}(h,(x,y))=|e|.
$$

The first is squared or quadratic loss; the second is absolute or $L_1$ loss. Both penalize positive and negative errors symmetrically.

|Error magnitude|Squared loss versus absolute loss|
|---|---|
|$0<\lvert e\rvert<1$|$e^2<\lvert e\rvert$|
|$\lvert e\rvert=0$ or $\lvert e\rvert=1$|The losses are equal|
|$\lvert e\rvert>1$|$e^2>\lvert e\rvert$|

The threshold 1 assumes the numerical scaling used in these formulas. Squared loss grows quadratically, so large errors receive much more weight than under absolute loss. This explains why changing the loss can change the fitted predictor and its sensitivity to large errors.

**Sketch to retain:** draw $e^2$ as a parabola and $|e|$ as a V-shaped curve on the same axes. They intersect at $e=-1,0,1$.

## 7. True risk: the quantity we want to minimize

> [!info] Definition — True risk
> The true risk, also called population risk or generalization error in the professor's notes, is the expected loss on a fresh example:
> $$
> L_{\mathcal{D}}(h)=\mathbb{E}_{z\sim\mathcal{D}}[\ell(h,z)].
> $$

The loss measures performance on one example; the risk averages it over the data-generating distribution. Frequently occurring inputs contribute more to this average than rare inputs.

Under zero-one loss, the expectation of an indicator equals the probability of its event:

$$
L_{\mathcal{D}}(h)=\mathbb{P}_{(X,Y)\sim\mathcal{D}}(h(X)\ne Y).
$$

With deterministic labels, this becomes

$$
L_{\mathcal{D}}(h)=\mathbb{P}_{X\sim\mathcal{D}_{\mathcal{X}}}(h(X)\ne f(X)).
$$

Ideally, assuming a minimizer exists, we would select

$$
h^*\in\operatorname*{arg\,min}_{h\in\mathcal{H}}L_{\mathcal{D}}(h).
$$

However, $\mathcal{D}$ is unknown, so we cannot generally evaluate this objective exactly from the training sample. This is the reason direct population-risk minimization is unavailable to the learner. Multiple minimizers are not the fundamental obstacle.

## 8. Empirical risk and the law of large numbers

### 8.1 Estimating an expectation

For i.i.d. observations $W_1,\ldots,W_m$ with finite $\mathbb{E}[|W|]$, the sample average estimates the population mean:

$$
\hat\mu_m=\frac{1}{m}\sum_{i=1}^{m}W_i
\longrightarrow\mathbb{E}[W]
\quad\text{as }m\to\infty.
$$

This is the law of large numbers (LLN). For a coin coded as 1 for heads and 0 for tails, $\mathbb{E}[W]=p$, and the observed fraction of heads estimates the unknown probability $p$.

The same reasoning applies to a function of the observations: average $g(W_i)$ to estimate $\mathbb{E}[g(W)]$, provided it is integrable.

### 8.2 Applying the idea to losses

For a fixed hypothesis $h$, take $W_i=\ell(h,z_i)$. This gives

> [!info] Definition — Empirical risk
> $$
> L_S(h)=\frac{1}{m}\sum_{i=1}^{m}\ell(h,z_i).
> $$
> This is the average loss on the training sample, also called training error.

Unlike true risk, empirical risk can be computed from the observed examples and the chosen hypothesis. Under zero-one loss,

$$
L_S(h)=\frac{\#\{i:h(x_i)\ne y_i\}}{m}.
$$

For a fixed $h$ with integrable loss, the LLN gives $L_S(h)\to L_{\mathcal{D}}(h)$. This motivates using empirical risk as a proxy for true risk.

## 9. Empirical risk minimization and its limitation

> [!info] Definition — Empirical risk minimization (ERM)
> An ERM learner selects a hypothesis with minimum empirical risk:
> $$
> A(S)=\hat h_S\in\operatorname*{arg\,min}_{h\in\mathcal{H}}L_S(h).
> $$

The notation $\operatorname*{arg\,min}$ denotes the **set of minimizers**, whereas $\min$ denotes the minimum numerical value. Writing $\in$ allows several hypotheses to attain the same minimum. A particular algorithm must select one of them.

ERM is a selection principle. How to solve the optimization problem efficiently is a separate issue. The introductory discussion assumes a minimizer exists and can be selected.

### 9.1 Why the LLN alone is insufficient

The LLN argument above fixes $h$ independently of the training sample. ERM instead selects $\hat h_S$ after examining that same sample. As the sample changes, the selected hypothesis can change too.

A sufficiently flexible class can contain hypotheses that exploit the particular training examples and behave badly elsewhere. Therefore, pointwise convergence for every fixed $h$ does not automatically establish

$$
L_S(\hat h_S)\approx L_{\mathcal{D}}(\hat h_S).
$$

This explains the warning in the professor's notes. One possible way to justify the approximation is to control deviations simultaneously over the class, rather than only for a single fixed hypothesis. Such a guarantee requires further assumptions and analysis.

> [!info] Definition — Generalization gap
> The generalization gap of the learned hypothesis is
> $$
> L_{\mathcal{D}}(\hat h_S)-L_S(\hat h_S).
> $$
> A large positive gap means that training performance substantially overstates performance on fresh data.

The gap is a signed difference, not necessarily nonnegative for every sample. Overfitting refers to fitting training data in a way that does not generalize well. **Zero training error alone does not prove overfitting**: a predictor can have both zero training error and zero true risk.

## 10. The PAC objective: small risk with high probability

Because $S$ is random and $\hat h_S=A(S)$ depends on $S$, the resulting true risk is itself random before the training sample is drawn. Different samples can produce better or worse predictors.

The lesson introduces **probably approximately correct (PAC)** learning through the objective of obtaining small true risk with high probability. A precise expression of this introductory goal is

$$
\mathbb{P}_{S\sim\mathcal{D}^m}
\left(L_{\mathcal{D}}(\hat h_S)\le\varepsilon\right)
\ge 1-\delta.
$$

- **Approximately correct:** the risk is at most a chosen tolerance $\varepsilon$.
- **Probably:** the probability of obtaining such a predictor is at least $1-\delta$.
- **Failure probability:** $\delta$ bounds the chance that the random training sample leads to risk greater than $\varepsilon$.

For example, $\varepsilon=0.05$ and $\delta=0.01$ would mean that at least 99% of independently drawn training samples produce a classifier whose population misclassification probability is at most 5%, if the relevant guarantee holds.

There are two distinct sources of probability here. Inside $L_{\mathcal{D}}(\hat h_S)$, we average over a fresh example while holding the trained predictor fixed. The outer probability concerns drawing the entire training sample and hence selecting the predictor.

The recording introduces the idea without a sample-size theorem. The displayed $\varepsilon,\delta$ notation makes that idea explicit; it is not a claim that arbitrary ERM already satisfies it. Arbitrarily small absolute risk also requires that sufficiently accurate prediction is possible, as in an appropriate realizable setting. With noise or an inadequate class, the best achievable risk need not be zero.

## 11. Worked example: perfect memorization and poor generalization

### 11.1 Data-generating mechanism

Let

$$
\mathcal{X}=[0,1]^2,\qquad
X\sim\operatorname{Uniform}([0,1]^2),\qquad
\mathcal{Y}=\{0,1\}.
$$

Let $A\subseteq[0,1]^2$ be an unknown square with area $1/2$, and define

$$
f(x)=\mathbf{1}_{A}(x)=
\begin{cases}
1,&x\in A,\\
0,&x\notin A.
\end{cases}
$$

Here $A$ denotes a geometric region, not the learning algorithm $A(S)$ used earlier. Uniform sampling on a unit-area domain implies

$$
\mathbb{P}(X\in A)=\operatorname{area}(A)=\frac12.
$$

The learner observes $m$ labeled points (12 in the lecture drawing), but does not see the true square boundary. Crosses denote positive examples and circles denote negative examples.

### 11.2 An unrestricted class permits memorization

Allow all binary-valued prediction functions on $\mathcal{X}$, with the usual measurability requirement when evaluating risk. Consider the rule

$$
\hat h_S(x)=
\begin{cases}
1,&\exists i\in\{1,\ldots,m\}:x=x_i\text{ and }y_i=1,\\
0,&\text{otherwise}.
\end{cases}
$$

It predicts 1 only at the exact positive training locations and 0 everywhere else. It does not label neighborhoods around the positive points.

Every positive training point receives 1, and every negative training point receives 0. Deterministic labels prevent a location from appearing with conflicting labels. Thus

$$
L_S(\hat h_S)=0.
$$

Since the loss cannot be negative, this rule is an empirical-risk minimizer. It is one possible ERM output, even though other minimizers exist.

### 11.3 Computing the true risk

Fix any finite training sample and define its positive locations by

$$
P_S=\{x_i:y_i=1\}.
$$

Since the input distribution is continuous and $P_S$ is finite,

$$
\mathbb{P}(X\in P_S)=0.
$$

The prediction outcomes are:

|Fresh input location|True label|Memorizing prediction|Loss|
|---|---|---|---|
|Outside $A$|0|0|0|
|Inside $A\setminus P_S$|1|0|1|
|At a location in $P_S$|1|1|0, but this event has probability zero|

Therefore,

$$
\begin{aligned}
L_{\mathcal{D}}(\hat h_S)
&=\mathbb{E}_{z\sim\mathcal{D}}[\ell(\hat h_S,z)]\\
&=\mathbb{P}(\hat h_S(X)\ne f(X))\\
&=\mathbb{P}(X\in A\setminus P_S)\\
&=\mathbb{P}(X\in A)=\frac12.
\end{aligned}
$$

Consequently,

$$
\boxed{L_S(\hat h_S)=0,\qquad L_{\mathcal{D}}(\hat h_S)=\frac12.}
$$

The generalization gap is $1/2$. Under this distribution, the memorizing rule has the same true error as the constant-zero classifier and as fair random guessing, despite perfect training accuracy.

Increasing the number of memorized points to any other finite number does not fix this particular rule: finitely many isolated points still have probability zero. The example shows that unrestricted ERM can select a bad solution, not that every empirical-risk minimizer is bad. Indeed, the true function $f$ also achieves zero empirical risk and has zero true risk.

## 12. Restricting the class: completing the homework

The proposed restriction is to use indicators of squares:

$$
\mathcal{H}_{\mathrm{square}}
=\{h_B:h_B(x)=\mathbf{1}_B(x),\ B\text{ is a square contained in }[0,1]^2\}.
$$

The following is a worked completion of the homework posed on your page 6 and the professor's page 8.

### 12.1 What does ERM choose now?

Each hypothesis is determined by a square $B$, so ERM becomes

$$
\hat B_S\in\operatorname*{arg\,min}_{B\text{ square in }[0,1]^2}
\frac1m\sum_{i=1}^{m}\mathbf{1}_{\{\mathbf{1}_B(x_i)\ne y_i\}},
\qquad
\hat h_S(x)=\mathbf{1}_{\hat B_S}(x).
$$

Because the true square $A$ belongs to this class and labels the data perfectly, the minimum empirical risk is zero. Thus **any square containing all positive training points and excluding all negative training points is an ERM solution**.

The data need not determine a unique square. An actual algorithm can specify a tie-breaking rule among consistent squares. The solution is not necessarily the true square $A$, whose boundary remains unknown.

If there are no positive training examples, the requirement to contain positives is vacuous; a square avoiding all negative examples is consistent. The true square remains one such choice under the stated assumptions.

### 12.2 Why the restriction matters

The classifier now predicts 1 throughout a geometric region, including previously unseen inputs inside it. The class encodes a structural assumption: positive labels occupy a square. This is an example of **inductive bias**, an assumption that allows observed examples to inform predictions elsewhere.

For any candidate square $B$, errors occur precisely where $A$ and $B$ disagree. Under the uniform distribution,

$$
L_{\mathcal{D}}(h_B)
=\mathbb{P}(X\in A\triangle B)
=\operatorname{area}(A\triangle B),
$$

where $A\triangle B=(A\setminus B)\cup(B\setminus A)$ is the symmetric difference. The first region contains missed positives; the second contains false positives. This formula is an explanatory derivation of what true risk means for the homework.

**Sketch to add:** draw the true square $A$ and a consistent candidate square $B$ over the sample points, then shade the portions belonging to exactly one square. Those shaded portions represent the true error region.

Restricting the class removes the isolated-point memorizer used above. It does not make finite-sample training error identical to true risk. A generalization guarantee still requires a sample-size and complexity argument.

> [!warning] A square is not an arbitrary bounding rectangle
> Joining the minimum and maximum coordinates of the positive points generally creates a rectangle, not a square. The homework specifies squares. Its ERM answer is any consistent square, not automatically the coordinatewise bounding box.

## 13. Preview of the next lecture

The final page of the professor's notes explicitly previews a finite hypothesis class:

$$
\mathcal{H}=\{h_1,\ldots,h_M\},\qquad M=|\mathcal{H}|.
$$

The next step is to relate the number of hypotheses $M$, the sample size $m$, and generalization performance. The family of all squares with continuously varying boundaries is still infinite; restricting its structure is not the same as making its cardinality finite.

Near the beginning of the recording, the professor anticipates using the **union bound**. Its correct statement is

$$
\mathbb{P}\left(\bigcup_{j=1}^{M}E_j\right)
\le\sum_{j=1}^{M}\mathbb{P}(E_j).
$$

It bounds the probability that at least one of several bad events happens and does not require those events to be independent. The transcript incorrectly reverses the inequality in words.
