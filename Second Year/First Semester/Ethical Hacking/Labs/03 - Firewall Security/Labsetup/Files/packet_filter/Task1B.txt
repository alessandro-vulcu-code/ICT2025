### Task 1.B, punto 2 — Tracciamento degli hook Netfilter

HostA → host Docker

[27100.950519] seedFilter: PRE_ROUTING 10.9.0.5 -> 10.9.0.1 (ICMP)
[27100.950535] seedFilter: LOCAL_IN 10.9.0.5 -> 10.9.0.1 (ICMP)

La richiesta entra in PRE_ROUTING. Poiché 10.9.0.1 è un indirizzo dell’host Docker, il pacchetto viene consegnato localmente e passa per LOCAL_IN.

Host Docker → HostA

[27106.506631] seedFilter: LOCAL_OUT 10.9.0.1 -> 10.9.0.5 (ICMP)
[27106.506641] seedFilter: POST_ROUTING 10.9.0.1 -> 10.9.0.5 (ICMP)

La richiesta è generata sull’host Docker, quindi passa per LOCAL_OUT e poi per POST_ROUTING prima di uscire verso HostA.

HostA → Internet

[27111.753191] seedFilter: PRE_ROUTING 10.9.0.5 -> 1.1.1.1 (ICMP)
[27111.753205] seedFilter: FORWARD 10.9.0.5 -> 1.1.1.1 (ICMP)
[27111.753210] seedFilter: POST_ROUTING 10.9.0.5 -> 1.1.1.1 (ICMP)

La richiesta entra nell’host Docker tramite PRE_ROUTING. Poiché 1.1.1.1 è una destinazione esterna, l’host inoltra il pacchetto tramite FORWARD. Prima di uscire, il pacchetto passa per POST_ROUTING
